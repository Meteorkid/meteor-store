# 卖软件方案(2026-11-03)

> 约束前提(已与刘鑫宇确认):每周投入 ≤3 小时、两条线并行、倾向用免费换流量。
>
> 这份文档只回答一个问题:**在 3 小时/周的预算下,做什么动作有可能真的卖出东西。**

---

## 一、诊断:为什么现在卖不出去

按严重程度排序,前两条都属于「即使来一万个访客也赚不到钱」的结构性问题。

### 1. 转化漏斗断裂:用户无法试用,只能盲买 ⚠️ 最致命

| 事实 | 证据 |
|---|---|
| XIsland(¥12)、XNook(¥9)的 DMG 全部 `gated: true` | `src/data/products.ts` 的 `downloads[].gated` |
| 门控下载要求 session + 该产品授权,否则 401 / 403 | `src/app/api/download/[productId]/route.ts` L66-77 |
| 客户端已内置 MSL1 授权协议与 **14 天试用** | `docs/process/software-licensing-backend.md` |
| 线上 trace 接口存在 | `GET /api/software-licenses/trial` → 405(路由在,是方法不对) |

**死锁**:试用要装得上 → 装得上要下载 → 下载要买过 → 买过要先相信它有用 → 相信要有试用。

实测后果:页面写着「Free — 基础功能/单代理」,但 `products.ts` 里 XIsland **只有一个下载条目且为 gated**,免费档没有任何可下载的产物。这是页面在承诺一件做不到的事。

**对一个 ¥9-12 的 macOS 小工具,盲买转化率通常低于 0.3%。** 这不是流量问题。

### 2. 定价低于获客成本

| 项 | 现在 | 算术 |
|---|---|---|
| XIsland | ¥12 买断 | 2% 转化 → 月入 ¥3000 需 12,500 访客/月 |
| XNook | ¥9 买断 | 同上 |
| Meteor Pass | ¥9/月、¥19/年、¥99 买断 | 年付 ¥19 折合 ¥1.6/月,低于任何支持成本 |

个人站没有任何分发渠道能稳定产出 12,500 访客/月。**这条路在数学上不成立,不是执行不到位。**

参考:同类 macOS 灵动岛工具(NotchNook)定价 $25,说明这类工具有真实支付意愿——但人群在英文圈、美元定价。

### 3. 全站零埋点

`src/` 与 `next.config.ts` 中无 GA / Plausible / Umami / PostHog / Clarity 任何一处。
结论:目前无法回答「来了多少人、看了什么、在哪一步走掉」。**任何优化都无法验证。**

### 4. 人群与渠道错配

| 产品 | 真实用户画像 | 站点面向 |
|---|---|---|
| XIsland | 用 Claude Code / Cursor 的 **macOS 开发者** | 中文站、人民币、中文 SEO |
| XNook | macOS 效率工具用户 | 同上 |

这批人密集在 GitHub / X / Hacker News / Product Hunt / Reddit r/ClaudeAI,几乎不通过中文搜索找工具。

### 5. 注意力稀释

9 款产品里 **7 款 `price: 0`**,首页与 `/products` 的视觉重心被免费品占据,真正在卖的 2 款不突出。用户看不出"这里该买什么"。

## 二、3 小时/周 下唯一可行的结构

三条约束彼此冲突:并行 = 每条只剩 1.5 小时;而内容起量需要高频产出。所以要靠**时间性质**区分,而不是平均分配:

| 线 | 性质 | 投入 | 产出形态 |
|---|---|---|---|
| **海外 XIsland** | **一次性战役**,打完只吃长尾 | 集中在 2 个周末,之后每周 0.5h 维护 | 一次 launch + 常驻落地页 |
| **中文申请工具** | **持续产出**,模板化 | 每周 2h 固定 | 小红书/B站固定栏目 |

关键在**一次性 vs 持续**不抢同一份精力。想两边都"持续运营",3 小时/周做不到,不要试。

### 中文线的主推选择(重要)

不要推 Chakra Visualizer 或 Tollow 当主线。理由:

- Chakra(手势忍术)传播力强但**人群泛、无付费场景**,适合做爆点不适合做主线
- Tollow(打字练习)人群泛,且免费档已够用
- **真正该主推的是「博士申请日历」和「硕士日历」**
  - 需求真实且集中(申博/考研是明确的搜索行为)
  - **你本人是当事人**,内容可信度天然高于任何搬运号
  - 工具即内容,不需要写推广长文
  - 与你的港科大申请主线完全重合:推广过程本身在积累领域认知

## 三、执行计划(12 周)

### 第 0 周(本周,一次性 2-3 小时):修漏斗 + 装表

没有这两件,后面所有动作都无法验证。

**动作 A:打通试用(1 行改动)**

```ts
// src/data/products.ts — XIsland / XNook 的 downloads[]
gated: true  →  gated: false
```

**前置必须确认**(否则等于白送):
1. XIsland 1.13.0 与 XNook 1.3.16 的客户端**确实调用了 MSL1 接口并强制校验签名**
2. 14 天到期后未激活会**锁定功能**,而不是仅仅弹个提示

验证方法:断网启动试用版 → 确认仍能工作但 7 天后租约到期 → 清空 keychain/偏好设置后重启 → 确认试用不重置。任一条不成立就先别开放下载。

**动作 B:接访问统计**

推荐 **Cloudflare Web Analytics**:免费、无 cookie、无合规负担、一行 script 放进根布局。
次选 Umami Cloud(免费额度 10k events/月)。

只要三个数:日 UV、XIsland 详情页 UV、下载点击率。

### 第 1-2 周(一次性 4 小时,集中在周末):XIsland 英文 landing

现在 `/zh/products/xisland` 是中文的。海外 launch 需要一个英文页:
- 首屏一句话:**"A Dynamic Island for your AI coding agents."**
- 一次 15 秒无声演示(你已有 `promo/xisland-landscape-1920x1080.mp4`,24s 可剪)
- 价格 **$12 买断**(不是 ¥12 折算成 $1.7 —— 那是自杀定价)
- 明确的 **Start 14-day trial** 按钮,不需要邮箱

### 第 3 周:Show HN + Product Hunt(一次性战役)

文案见 `docs/growth/launch-copy.md`,可直接用。

现实预期:Show HN 首页能给 500-3000 访问,首发转化 1-3% → **10-40 个试用,1-3 单**。
这不是暴富,是一次性建立 GitHub star 基础和第一批真实反馈。

### 第 4-12 周:中文线固定产出(每周 2 小时)

固定栏目,一次录多条,不要靠灵感:

| 周 | 内容 | 形式 |
|---|---|---|
| 单周 | 「港科大 PhD 申请时间线:我做了什么」 | 小红书图文,配申请日历截图 |
| 双周 | 「申博日历怎么用:2028 fall 倒推」 | 15 秒录屏 |

**唯一要求**:每条结尾指向 `imagentx.top/phd`(或 masters),不要指向首页。落地页越具体,转化越高。

每条内容只做 1 个动作:让人点进那个具体工具页。

## 四、北极星指标

只看 4 个,不要看别的(第三方流量、点赞、star 数都是虚荣指标):

| 指标 | 含义 | 当前 | 12 周目标 |
|---|---|---|---|
| 试用启动数 | 装了并联网激活试用 | 0(不通) | 100 |
| 试用→付费率 | 真实产品力 | — | 3-8% |
| XIsland 详情页→下载点击率 | 落地页说服力 | — | >15% |
| 付费订单数 | 结果 | 0 | 5-15 |

**如果试用启动到 100 而付费 0-1 单,说明产品没人要,不是营销问题。** 那时该做的不是加流量,是换产品。

---

## 五、明确不要做的事

3 小时/周 的预算经不起浪费:

- ❌ **不要买流量 / 投信息流**。¥12 的客单价,投放必亏。
- ❌ **不要做「全站所有产品都推」**。7 款免费品不产生收入,只稀释注意力。
- ❌ **不要为了 SEO 写长文**。中文搜索拿不到 macOS 开发者流量,周期 6 个月起,回报为零。
- ❌ **不要再做宣传片**。`promo/` 里已有 24s 和 64s 两条成片,质量足够。素材不是瓶颈,分发才是。
- ❌ **不要「先把价格改 0 攒用户」**。免费用户不回来付费,而且会永久锚定"这个作者的东西是免费的"。
- ❌ **不要同时开第三条产品线**。现在 9 款已经太多。

---

## 六、一句实话

按当前形态(¥9-12 买断、中文站、无分发),**这个组合的年收入期望在 0-800 元区间**。修完漏斗 + 做完一次 launch,合理预期是首年 1000-5000 元。

如果你要的是"赚到钱",这个量级不构成收入;如果你要的是"有真实用户、有 star、有作品集、申请材料里能写'独立开发者,产品有 N 个付费用户'",那这套动作是对的,而且**对 2028 港科大申请的价值高于那几千块**。

这两件事不冲突,但要认清主次。
