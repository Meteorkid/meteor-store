给 Claude Code 点「允许」这件事，一天要切几十次窗口。我把它搬到灵动岛上了。

平时我同时开好几个 AI 编码代理：Claude Code 两三个会话、Cursor 一个窗口。

烦的不是启动它们，是每次要写文件、跑命令，都得停下来等我批准：

切窗口 → 找到那个终端 → 看清楚它想干嘛 → 点允许 → 再切回来

一天几十次，节奏全碎。

所以写了个工具，把这些代理收进屏幕顶部一个灵动岛里：

- 要权限时，岛上直接出现「允许 / 拒绝」
- 代理提问时，按 `⌘1` / `⌘2` 选
- 审阅计划，也是在岛上过
- 点一下，跳回对应的 iTerm2 标签页
- 顺带能看到谁在跑、谁卡住、谁在等你

原生 Swift，四个代理挂着大概 40MB。面板是非激活窗口，点它不会抢走编辑器的焦点，拖到副屏会自己跟过去。

代理走的是各家自己的 hooks / settings，内置 30 来个：Claude Code、Codex、Cursor、Gemini CLI、Trae、Windsurf、Cline……

有几个我还在逐个验证，README 里列了每个的真实状态。
