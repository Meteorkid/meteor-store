# 电鸭社区 复盘帖（2026-11-05）

> **核心判断：这里不能发产品介绍帖。** 电鸭主页 90% 是招聘与外包，用户意图是找工作/接活，不是找工具。产品帖在这里的自然点击率会明显低于 V2EX。
>
> 但它有一个合法且被欢迎的入口：**「独立开发复盘」**。写「一个人做产品，第一批用户从哪来」，在那里互动质量很高，而且受众本身就是自由职业开发者——用 AI 编程工具的比例高于普通社区。
>
> 一句话：**换角度，不换事实；产品只出现两次（开头一句、结尾一句）。**

## 三、正文（复制粘贴）

> 正文里**没有任何 Markdown 标记**（没有 `##`、`**`、反引号），因为电鸭编辑器是否解析 Markdown 无法确认，带符号粘贴可能露出原文符号。想强调某句，粘完用编辑器工具栏手工加粗。段落之间保留空行。

```
不是推广帖，是一个月的账，顺便求个答案。

先说产品：X Island，Mac 上把 AI 编程工具（Claude Code、Codex、Cursor 这些）的状态和权限请求放到刘海上，不用来回切窗口点「允许」。一个人做的，做了五个多月。

为什么做：我一天要切几十次窗口去点那个允许，烦到自己动手。

一、发出去之后，真实的数据是这样

11 月 3 号晚上在 V2EX 发了一帖，没投任何广告，没找任何人转发。

- 从 V2EX 点进来的：19 次
- 商品页 PV：80（此前 30 天加起来是 28）
- 发出的永久激活码：4 个
- 新增注册：3 个
- GitHub star：还是 1

也就是说，19 个人点进来，4 个人领了码，3 个人注册。按「点击 → 领码」算是 21%。

对一个没做任何投放的产品，这个数我不嫌少。但它把一个更要紧的问题摊开了：我以为用户是没被说服，其实用户是没找到路。

二、三个我自己踩的坑

坑一：领码入口埋太深

最早只有下载按钮。有人下完，回头问「哪里领激活码」——他甚至没注册就走了。

这不是设计问题，是我默认了「用户会自己翻页面」。真实情况是，他从帖子点进来，眼睛只找「下载」两个字。

后来在下载区下面加了一行提示，又在页面顶部加了个「免费领取激活码」的按钮，未领取和已领取显示不同文案。

坑二：没买苹果开发者证书

App 是本地临时签名（adhoc），装完第一次打开会提示「已损坏，无法打开」。

我自己知道执行一句 xattr -cr 就行，但第一个用户不知道。他只会得出一个结论：这东西是坏的。

现在下载区直接把这句命令印出来了。但我到现在也没买那张 99 美元/年的证书——这是这个月最该花、我一直没花的钱。

坑三：闭源在中文社区是负分

我把「接入矩阵」和每个版本的验收记录全公开了，但客户端本身闭源。

英文社区对闭源工具宽容一些，中文技术社区第一反应是「凭什么信你」。这条我暂时没有解法，只能靠公开的验收记录一点点换。

三、我接下来打算这么干

按我的判断排了个序，从「人已经在找工具」到「人只是路过」：

1. V2EX 程序员节点 —— 已发第一帖，隔两天发技术帖，不发第二篇产品帖
2. linux.do —— 受众最对口，但要先攒够信任等级
3. 小众软件发现频道 —— 编辑会实测，收录后是永久入口，值一次认真写
4. 掘金 —— 技术文的长尾，主要吃搜索
5. 电鸭、即刻 —— 认知渠道，不是转化渠道

四、想请教一个问题

你们做独立产品，第一批真实用户是从哪来的？

我现在的样本只有 4 个人，还想不出「可复现」的办法。如果有人是从「在社区里认真回答问题」起量的，特别想听具体怎么做的——不是方法论，是你实际发了什么、在哪儿发的。

产品在这儿，现在限时免费，不着急下也没关系：https://www.imagentx.top/zh/products/xisland
```

## 五、会被追问什么

| 问题 | 答法 |
|---|---|
| 「21% 怎么算的」 | 19 次点击里 4 个领码。分子分母都在正文写了，直接引用 |
| 「下载多少」 | 老实说：下载接口 7 次，里面混了我自己复测，所以不敢当转化率用 |
| 「为什么不做 Windows」 | 一个人做，先做自己每天用的平台。Windows 版不在近期计划 |
| 「闭源怎么信」 | 接入矩阵、每版本验收记录全公开，能逐格查「验到哪一步」。信不信由你，但至少可核 |
| 「要不要合伙」 | 这篇不是招人帖。有人问就引到「项目」模块，别在评论里谈条件 |
