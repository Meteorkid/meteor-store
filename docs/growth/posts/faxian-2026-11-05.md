# 小众软件 发现频道 投稿（2026-11-05）

> **三条调研结论，都会直接影响成败**：
>
> 1. **不是表单提交，是去论坛发帖。** `faxian.appinn.com` 会自动跳到 `meta.appinn.net/c/faxian/10`，是一个 Discourse 分类。要先注册论坛账号。
> 2. **新账号会被临时禁用**，直到第一条内容通过人工审核（官方规则原文：「新用户在审核通过前会被系统临时禁用账号，审核通过后自动解禁」）。也就是注册完发帖然后等，别以为发失败了又发一遍——重复发布算违规。
> 3. **发现频道的主要读者是编辑测评团队，不是普通用户**（规则原话）。正文要写成「方便编辑照着写介绍」的信息密度，不是营销文案。

## 三、正文（全选复制，粘进帖子）

```
【开发者自荐】X Island - 在 MacBook 刘海上批准 Claude Code 的权限请求

用途：把 AI 编程工具（Claude Code、Codex、Cursor、Gemini CLI 等）的运行状态和权限请求放到 MacBook 刘海上，不用切窗口点「允许」。

支持平台：macOS 14 及以上，Intel 与 Apple Silicon 都可以。

特点：

- 代理要写文件或执行命令时，权限请求直接出现在刘海上，在岛上选「允许」或「拒绝」，不用切回终端
- 代理提问（单选、多选、自由输入）也能在岛上回答，⌘1 / ⌘2 直接选选项
- 点会话卡片可以跳回它所在的 iTerm2 标签页
- 同时跑多个代理时每路一张卡片，区分在跑、在等、出错
- 支持 30 多个客户端，每一个都标注了是「可以在岛上审批」还是「只能查看状态」；除 Claude Code / Codex / Cursor 外，还有 Kimi、通义千问、DeepSeek、GLM、CodeBuddy、Trae 国内版这些中文工具

界面有中文。客户端闭源，但接入矩阵和逐版本的验收记录是公开的。

价格：现在限时免费，注册一个账号即可领永久激活码（最多 3 台设备）。活动结束后为买断制，12 美元。

官网：https://www.imagentx.top/zh/products/xisland

一个需要提前说明的地方：安装包用的是本地临时签名，没有购买苹果开发者证书。首次打开若提示「已损坏，无法打开」，在终端执行下面这句即可，不是文件有问题：

xattr -cr "/Applications/X Island.app"

截图见楼下。
```

## 五、提交步骤

1. 注册 `meta.appinn.net`（常用邮箱）
2. 设置 → 个人资料 → 用户名改成 `Meteorkid`
3. 进入「发现频道」分类 → 新建主题
4. 标题粘本文标题，正文粘第三节内容，加 4 个标签：`macos` `效率工具` `ai` `claude`
5. 拖入 3 张截图
6. 发布 → 等人工审核（新账号被临时禁用属正常）
7. **同时**私信管理员 `@Qingwa` 送一个激活码

第 7 步是官方规则第 5.1 条明确鼓励的（「付费产品请私信管理员兑换码，降低评测成本」）。即使现在免费也给一个，并说明「评测可直接用这个码，不用注册」。这条私信对收录概率的影响比正文更大。

## 六、可能被问到的问题（提前想好答法）

| 编辑/用户会问 | 答法 |
|---|---|
| 和别的刘海工具什么区别 | **不要争「谁先做」**。答：多数同类是「看状态」，我们重点是**能把权限决定回传客户端**；另外覆盖了 Kimi / 通义 / DeepSeek / CodeBuddy / Trae 国内版，这块没人做全 |
| 为什么不开源 | 客户端闭源，但接入矩阵、逐版本验收记录、兼容性 JSON 全部公开在 `Meteorkid/XIsland`，想核「支持到哪一步」可以逐格查 |
| 为什么要注册 | 下载不用注册，装了能试用 14 天。注册只为发**永久**激活码，否则无法绑定设备 |
| 会不会上传代码 | 事件在本机处理，不上传代码内容。这句必须与公开验收记录一致，别夸大 |
| 支持 Windows 吗 | 不支持，仅 macOS |

## 七、不要做的事

- 不要用第二个账号回复自己的帖子（第 11 条）
- 不要在别人帖子下推自己的产品（第 18 条）
- 不要写「回帖留邮箱」（第 5.2 条），收集邮箱用表单
- 发布后**不要删帖重发**（第 8 条）：帖子会自动同步到 Telegram / Twitter / Fediverse，删了那些链接全部 404，重发会被拒
- 更新用「回复」把帖子顶起来，不要发新帖（第 8.1 条）
