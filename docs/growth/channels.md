# 渠道矩阵（2026-11 版）

> 判定标准不是「哪里人多」，是三个条件同时成立：
> ① 用户已经在用 AI 编程工具 ② 他会去那里找工具（不是找工作/看新闻） ③ 我发一次能被永久检索到。

## 一、排序

| 优先级 | 渠道 | 受众匹配 | 门槛 | 生命周期 | 状态 |
|---|---|---|---|---|---|
| P0 | V2EX「程序员」节点 | 高 | 无 | 3–7 天 | 技术帖已写好，待发 |
| P0 | linux.do「开发调优」 | **最高** | 需 TL1 | 1–2 周 | 需先刷 TL1 |
| **P1** | **小众软件 发现频道** | 高 | 人工审核 | **永久 + SEO** | **尚未提交** |
| P1 | 掘金 | 中高 | 无 | 数周 + 搜索长尾 | 未发 |
| P2 | 电鸭「独立产品」 | 中 | 注册 + 活跃 | 1–2 周 | 未发 |
| P2 | 即刻 | 中 | 需人设 | 1–2 天 | 未发 |
| P3 | 少数派 | 高 | 投稿审核 1–2 周 | 很长 | **等签名修好再投** |
| P3 | 小红书 / B 站 | 低（认知） | 高（要做视频） | 长 | 暂缓 |

## 二、小众软件 发现频道（性价比最高的新增渠道）

入口：`faxian.appinn.com`（论坛 `meta.appinn.net/c/faxian/10`），**开发者自助提交，人工审核**。

已有大量 `【开发者自荐】xxx` 的成功先例，macOS 效率工具是他们的主力品类，和 XIsland 的形态（菜单栏 / 灵动岛）完全对口。

他们的硬性规则（来自官方公告）：

- 标题认真写，不要标题党
- **必须配图**，没有截图的会被当垃圾贴
- 语言平实直白，说明用途、特点、为何推荐
- **必须给官网文字链**；只有链接没有内容的按 SEO 贴处理
- 首次发主题且有广告嫌疑的会被移入「帖子墓地」，可申诉

提交模板要点：

```
标题：【开发者自荐】X Island — 把 Claude Code 的权限审批搬到 macOS 灵动岛上
标签：macos / ai / 效率工具
用途：一句话
特点：3–5 条，每条一行
截图：至少 1 张，最好是权限审批那一屏
官网：https://www.imagentx.top/zh/products/xisland
```

**风险**：编辑会实测安装包。adhoc 签名会被 Gatekeeper 拦，可能因此被标注或拒收。这是唯一值得先花钱的地方（$99/年）。

## 三、电鸭社区：可以发，但排最后

先给结论：**不要发电鸭产品介绍帖，要发「独立开发者复盘」**。

理由（依据对站点的实际观察）：

1. 电鸭是**远程工作招聘社区**，主力板块是招聘、职场讨论、自由职业。社区潜规则原话是「与工作或职场相关的话题，在这里更受欢迎」「非传统坐班的工作机会会被优先展示」。
2. 用户意图是**找工作 / 接活**，不是找工具。产品帖在这里的点击转化会明显低于 V2EX。
3. 但它确实有合法入口：**「独立产品」板块**，以及 2026-09 上线的**「项目」模块**（官方帖子称已收录 670 个项目，可为项目找人）。这两处发产品不算违规。
4. 它的真实价值不是下载量，是**那里的人本身就是自由职业开发者**，用 AI 编程工具的比例高于普通社区。

### 发法：换角度，不换内容

不要写「我做了个工具」。写**「独立开发者做这个产品，第一个月的数据」**：

```
标题：做了个 macOS 工具，在 V2EX 发了一帖，两天来了 5 个真实用户
正文骨架：
1. 产品是什么（两句，链接放最后）
2. 为什么做：我一天要切几十次窗口点「允许」
3. 数据不美化：帖子看了 8 次点击，来了 5 个领激活码的，GitHub star 还是 1
4. 踩的坑：① 领码入口埋太深，有用户下载完找不到 ② 没买苹果证书，用户装完显示「已损坏」
5. 求问：你们做独立产品，第一批用户从哪来的？
```

这个角度在电鸭是**被欢迎的内容**（那里「自由职业」「独立开发接盘甲方」的帖子互动很好），而且不违反「与职场相关」的偏好。产品只出现一次。

### 时机

- 先把 V2EX 技术帖发完、拿到第二轮数据，再来写这篇复盘——**没有数据就没有复盘**。
- 最好是「两周后」，届时能写出更完整的第一批用户曲线。

## 四、掘金

技术文可直接发，无审核门槛，搜索长尾比 V2EX 好（百度收录快）。
同一个技术帖改一遍就能发，改动量最小。但掘金读者偏向「学知识」，产品链接放文末即可。

## 五、少数派：等签名

受众极度对口（macOS 效率工具的核心读者），但投稿要图文完整、审核 1–2 周，编辑一定会实测安装包。**adhoc 签名状态下投稿，等于把「已损坏」这一步送到编辑面前。** 建议买了 Apple Developer、完成公证之后再投。

## 六、暂不做

| 渠道 | 原因 |
|---|---|
| Show HN | 同类已有 coucou（6.9k star，MIT），闭源 + 重复会被当场指出 |
| Reddit | 延后；需换差异化角度（覆盖国产工具），且账号 karma 不够 |
| XNook 单独发帖 | 无一句话钩子，且同 ID 连发自家产品会被认成推广号 |
| Product Hunt | 一次性机会，需要 5 图 + 完整素材 + 英文化，放到有 100 star 之后 |

## 七、比发帖更高杠杆的一件事

`jaywcjlove/awesome-mac`（**117,735 star**）和 `hesreallyhim/awesome-claude-code`（**57,237 star**）都是活跃仓库，接受 PR 收录。

- 这两个是目标用户**主动找工具**时会翻的导航，收录后是永久入口，且能持续带来长尾
- 成本是一次规范 PR，不是发帖
- 前提：README、截图、Release 都要像样（这部分已经具备）

注意：两个仓库都有 CONTRIBUTING 和分类要求，条目格式不对会被直接关。**自荐类 PR 在 awesome 列表里是允许的，但不能只加链接不写说明。**
