# 渠道矩阵（2026-11 版）

> 判定标准不是「哪里人多」，是三个条件同时成立：
> ① 用户已经在用 AI 编程工具 ② 他会去那里找工具（不是找工作/看新闻） ③ 我发一次能被永久检索到。

## 二、小众软件 发现频道（性价比最高的新增渠道）

入口：`faxian.appinn.com` → 自动跳到 `meta.appinn.net/c/faxian/10`。

**它不是投稿表单，是论坛（Discourse）分类，要发帖。** 我原以为可以自助提交，实测是发主题帖 + 人工审核，规则见 `meta.appinn.net/t/topic/43728`。

已核过的硬规则（文案已按这些写，见 `posts/faxian-2026-11-05.md`）：

- **新账号在首帖过审前会被临时禁用**，所以「发完看不到」是正常的，别重发（重发算违规）
- 标题不得含「最强 / 必备 / 史上最强」，不得含网址；`【】` 内只放分类
- **付费软件必须标价，免费试用也算付费软件**；售价超 100 元/年需走付费「商业推广」
- 必须给**官网直链**，短链/跳转链接不接受
- **「必须注册才能用」必须注明**；**有无中文界面必须注明**
- 不要复制粘贴官网介绍，不要啰嗦
- 不要乱加标签（站内已存在：`macos` `效率工具` `ai` `claude` `codex`）
- **昵称会作为「介绍这款软件时的署名」**，注册后第一件事是改成 `Meteorkid`
- 付费产品可私信管理员 `@Qingwa` 送兑换码降低评测成本（规则第 5.1 条鼓励）

**发现频道的读者主要是编辑测评团队，不是普通用户**（规则原话）。所以正文要按「方便编辑照着写介绍」的信息密度写，不是营销文案。

**风险**：编辑会实测安装包。adhoc 签名会被 Gatekeeper 拦，正文里已主动给出 `xattr -cr` 的解法——藏起来反而会被写成「装不上」。这是唯一值得先花钱的地方（$99/年）。

## 三、电鸭社区：可以发，但排最后

先给结论：**不要发电鸭产品介绍帖，要发「独立开发者复盘」**。

理由（依据对站点的实际观察）：

1. 电鸭是**远程工作招聘社区**，主力板块是招聘、职场讨论、自由职业。社区潜规则原话是「与工作或职场相关的话题，在这里更受欢迎」「非传统坐班的工作机会会被优先展示」。
2. 用户意图是**找工作 / 接活**，不是找工具。产品帖在这里的点击转化会明显低于 V2EX。
3. 但它确实有合法入口：**「独立产品」板块**，以及 2026-09 上线的**「项目」模块**（官方帖子称已收录 670 个项目，可为项目找人）。这两处发产品不算违规。
4. 它的真实价值不是下载量，是**那里的人本身就是自由职业开发者**，用 AI 编程工具的比例高于普通社区。

### 发法：换角度，不换内容

不要写「我做了个工具」。写**「独立开发者做这个产品，第一个月的数据」**：

```
标题：一个人做 Mac 工具的第一个月：V2EX 一帖带来 19 次点击、4 个激活码、0 个 star
正文骨架：
1. 产品是什么（两句，链接放最后）
2. 为什么做：我一天要切几十次窗口点「允许」
3. 数据不美化：19 次点击 / 商品页 80 PV / 4 个激活码 / 3 个新注册 / star 还是 1
4. 踩的坑：① 领码入口埋太深，有用户下载完不知道去哪领 ② 没买苹果证书，装完显示「已损坏」 ③ 闭源在中文社区是负分
5. 求问：你们做独立产品，第一批用户从哪来的？
```

上面数字是 2026-11-05 11:00 的实查值（`software_license_codes` + nginx referer）。完整正文见 `posts/eleduck-2026-11-05.md`。**发之前若数据变了，标题和正文两处一起改。**

这个角度在电鸭是**被欢迎的内容**（那里「自由职业」「独立开发接盘甲方」的帖子互动很好），而且不违反「与职场相关」的偏好。产品只出现两次（开头一句、结尾链接）。

### 时机

两个窗口都成立，选一个：

- **本周内发**：数据是「首帖后两天」，样本小但新鲜，而且能赶上后续渠道的连带曝光
- **V2EX 技术帖发完 + 一周后再发**：数字更厚，能画出第一周曲线。**但标题里的数字要重算，正文第二节整段替换**

不要等超过两周。电鸭的热度机制是回帖，一个没有讨论的旧帖会一直沉在下面。

## 四、掘金

技术文可直接发，无审核门槛，搜索长尾比 V2EX 好（百度收录快）。但它的规则和前两个渠道完全不同：

- **分类必选**（`人工智能` 或 `开发工具`），**标签必须是站内已存在的**，**摘要必须单独写**
- **正文里不要放外部链接。** 判断逻辑是「技术内容可以带推广，不能是软文带硬广」；链接放**评论区首条 + 作者简介**，正文只留仓库名（纯文本）
- 同一篇不能直接搬 V2EX 版：V2EX 读者嫌掘金版啰嗦，掘金读者嫌 V2EX 版没结构。改写稿见 `posts/juejin-2026-11-05.md`（约 2600 字，含 3 张表格与代码块）

## 五、少数派：等签名

受众极度对口（macOS 效率工具的核心读者），但投稿要图文完整、审核 1–2 周，编辑一定会实测安装包。**adhoc 签名状态下投稿，等于把「已损坏」这一步送到编辑面前。** 建议买了 Apple Developer、完成公证之后再投。

## 六、暂不做

| 渠道 | 原因 |
|---|---|
| Show HN | 同类已有 coucou（6.9k star，MIT），闭源 + 重复会被当场指出 |
| Reddit | 延后；需换差异化角度（覆盖国产工具），且账号 karma 不够 |
| XNook 单独发帖 | 无一句话钩子，且同 ID 连发自家产品会被认成推广号 |
| Product Hunt | 一次性机会，需要 5 图 + 完整素材 + 英文化，放到有 100 star 之后 |

## 七、比发帖更高杠杆的一件事

`jaywcjlove/awesome-mac`（**117,735 star**）接受 PR 收录，条目格式、字母序、图标规则都已核过，文案见 `posts/awesome-pr-2026-11-05.md`。

`hesreallyhim/awesome-claude-code`（**57,237 star**）**暂时不能投**：CONTRIBUTING 明写「产品需要注册或付费是 review 的 blocker」，我们领激活码必须注册；而且它只收网页 issue 表单，不接受 PR，也不支持 `gh` 命令行提交。

另一个必须先知道的：awesome-mac 的 `Menu Bar Tools` / `AI Tools` 两节里，同类已有 Agent Island、CodexIsland、**Perch**（原文写 answer from the notch）、**Topnotchers**（原文写 permission prompts answered from the notch）、HeyMate、Notchly、cctop。

**所以条目不能只写「在刘海上审批」**，会被当重复关掉。唯一没被占的是「覆盖广度（30+，含中文客户端）+ 每格标注可审批/仅观察」。
