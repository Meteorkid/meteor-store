### 第 1 张怎么拍（30 秒）

1. 打开 Claude Code（终端里跑 `claude`），随便让它改一个文件
2. 刘海弹出「允许 / 拒绝」时**先别点**
3. 按 `⌘⇧4`，然后拖框选中刘海那块 + 一点点背景
4. 存到 `图/`，改名 `xisland-03-权限审批-中文.png`

**不要整屏截图**——会带出壁纸、Dock、无关窗口，编辑一眼看出不专业。

## 硬规则（已逐条对过正文，你照抄就不会踩）

- 标题不许「最强/必备/史上最强」，不许带网址
- **付费必须标价，免费试用也算付费** → 正文已写「限时免费，之后 12 美元买断」
- **「领码要注册」必须写明** → 已在正文
- **有无中文界面必须写明** → 已在正文
- 必须给官网直链，短链/跳转链接不收 → 已用产品页原始地址
- 不要复制粘贴官网介绍 → 正文是重写的
- 不要乱加标签 → 只加 4 个
- 不要用第二个账号回自己的帖、不要在别人帖下推产品
- **发完不要删帖重发**：会同步到 Telegram / Twitter / Fediverse，删了那些链接全 404，重发会被拒

## 审核期

新账号在首帖过审前会被**系统临时禁用**。发完看不见帖子是正常的，等就行，别重发。

## 发完立刻做的一步

私信管理员 `@Qingwa`，内容用 `4-私信管理员.txt`。

这是官方规则第 5.1 条明确鼓励的（「付费产品请私信管理员兑换码，降低评测成本」）。
即使现在免费也给一个码，并说明「评测可以直接用，不用注册」——这条私信对收录率的影响比正文更大。
