# 发帖顺序与操作卡

> 一个渠道一个文件夹，正文都是**纯文本**，打开全选复制即可。带 `1b-` 的是备选标题。
> 每个文件夹里还有一份「步骤」，写着分类/标签该填什么。

## 发帖顺序

| 顺序 | 渠道 | 文件夹 | 什么时候发 | 卡点 |
|---|---|---|---|---|
| ① | 掘金 | `02-掘金/` | **现在就能发** | 无 |
| ② | 电鸭 | `03-电鸭/` | **现在就能发** | 无 |
| ③ | 小众软件 | `01-小众软件/` | **补完截图再发** | 缺 3 张图 |
| ④ | awesome-mac | `04-awesome-mac/` | 随时，PR 形式 | 需你授权我提 |

**为什么掘金排第一**：它不审核、不吃时间窗口，发完就当长尾放着，百度收录最快。
**电鸭排第二**：它吃评论互动，越早发越有时间回帖。
**小众软件必须等图**：那个频道的读者是编辑，没图的会被当垃圾贴，规则里写得很直白。

## 每个渠道 30 秒操作卡

### ① 掘金

1. 打开 https://juejin.cn/editor/drafts/new
2. 标题 → `02-掘金/1-标题-推荐.txt`
3. 正文 → `02-掘金/3-正文-粘贴为Markdown.md`（**这个文件要按 Markdown 粘，别用纯文本模式**）
4. 点「发布」→ 分类选 **人工智能**，标签选 `AI编程` `Claude` `Agent`，摘要粘 `2-摘要.txt`
5. 封面 → `图/xisland-00-封面-英文原图.png`
6. 发布后：把 `4-评论区首条.txt` 发在自己的评论区并置顶

### ② 电鸭

1. 先补完个人资料（技能、履历），新号发帖有限制
2. 发帖 → 板块选 **自由职业**
3. 标题 → `03-电鸭/1-标题-推荐.txt`
4. 正文 → `03-电鸭/2-正文-直接粘贴.txt`
5. **不要**选招聘/外包类板块，会被直接删

**可选（2 分钟，优先级最低）**：顺手在 `/projects` 挂一个项目卡，文案在 `03-电鸭/4-项目模块-提交文案.md`。
项目广场 1,178 个项目、每天新增约 28 个，最新那批浏览量是个位数——**当长尾占位，别当流量渠道**。

### ③ 小众软件

1. 注册 `meta.appinn.net`，先把昵称改成 `Meteorkid`（规则：昵称就是日后介绍你时的署名）
2. 进「发现频道」分类 → 新建主题
3. 标题 → `01-小众软件/1-标题.txt`
4. 正文 → `01-小众软件/2-正文-直接粘贴.txt`
5. 加标签：`macos` `效率工具` `ai` `claude`
6. 传 3 张图（见 `01-小众软件/3-步骤与标签.md` 里的图清单）
7. **私信管理员 @Qingwa 送一个激活码** → 用 `4-私信管理员.txt`
8. 发完等审核。新账号在过审前会被临时禁用，**看不见帖子是正常的，不要重发**

### ④ awesome-mac

照 `04-awesome-mac/4-操作步骤.md` 走。要动两个文件、插一个条目，5 分钟。

## 发之前 60 秒自检（三个平台通用）

- [ ] 正文里**没有** http 链接的，只有掘金需要这样；小众软件和电鸭**必须**有官网链接
- [ ] 标题和正文里的数字一致（19 次点击 / 4 个激活码 / 3 个注册 / 1 star）
- [ ] 「限时免费，之后 12 美元买断」这句在，不能只写免费
- [ ] 「领激活码需要注册账号」这句在（小众软件硬规则）
- [ ] 没有出现「最强」「必备」「神器」这类词
- [ ] 头像/昵称像个人，不像推广号
