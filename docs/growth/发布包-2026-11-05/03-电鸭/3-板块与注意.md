# 电鸭 · 板块与注意

## 填什么

| 项 | 值 |
|---|---|
| 板块 | **自由职业**（`eleduck.com/categories/23`） |
| 备选板块 | `AI`（`/categories/29`） |
| **不要选** | 招聘 / 外包零活 / 企业直招，会被直接删 |
| 标题 | `1-标题-推荐.txt` |
| 正文 | `2-正文-直接粘贴.txt` |

## 三条注意

**1. 正文里没有任何 Markdown 标记。**
电鸭编辑器是不是解析 Markdown 我不能确认，所以标题层级用「一、二、三」纯文本，
加粗也去掉了。想强调某句，粘完用编辑器工具栏手工加粗（就一两处，别多）。

**2. 标题里的数字必须和正文一致。**
19 次点击 / 4 个激活码 / 3 个新注册 / 1 star。
如果发之前数据变了，**标题和正文第二节要一起改**，不能只改一处。

**3. 新号发帖可能有限制。**
先把个人资料（技能、履历）补完整再发，否则容易被限流。

## 这个帖子的目标不是下载量

电鸭的用户意图是找工作/接活，产品转化会低于 V2EX。

它的价值在评论区：那里的人本身就是自由职业开发者，用 AI 编程工具的比例高于普通社区。
所以**有人认真提问一定要回**，这个板块一半的价值在对话里。

## 会被追问什么

| 问题 | 答法 |
|---|---|
| 21% 怎么算的 | 19 次点击里 4 个领码，分子分母都在正文写了 |

| 要不要合伙 | 这篇不是招人帖，有人问就引到「项目」模块 |
