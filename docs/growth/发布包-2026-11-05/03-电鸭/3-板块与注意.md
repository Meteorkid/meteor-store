## 三条注意（仍然成立）

**1. 正文里没有任何 Markdown 标记。**
电鸭编辑器是否解析 Markdown 未确认，所以标题层级用「一、二、三」纯文本。

**2. 标题里的数字必须和正文一致。**

**3. 新号发帖限制。** 新号发带链接的内容，触发审核的概率显著更高——
这很可能也是这次被隐藏的叠加因素之一。

## 这次真正的教训

这篇稿子的内容是好的（数据真实、PV 那个洞察有说服力），问题出在**放错了地方**。

电鸭是靠招聘方付费发布赚钱的平台。免费账号在广场发产品相关内容，
等于占它的收费位。这类平台不会跟你讨论内容质量，直接隐藏。

**「这个板块人多」≠「这个板块允许我说话」。** 判断渠道先看板块定位和盈利方式，再看流量。
