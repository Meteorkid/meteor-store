# awesome-mac · 操作步骤

仓库：`jaywcjlove/awesome-mac`（约 117k star），接受 PR 自荐，规则已核过。

## 一个必须先知道的事

`Menu Bar Tools` 这一节里，同类已经很挤了：

| 已有条目 | 它写的卖点 |
|---|---|
| Agent Island | 刘海显示 Claude Code / Codex 会话状态 |
| CodexIsland | 刘海显示 rate limit 和花费 |
| **Perch** | **「answer from the notch」** |
| **Topnotchers** | **「permission prompts answered from the notch」** |
| HeyMate | 刘海里跑 agent，批准 plan |
| Notchly | 轻量灵动岛 + AI 代理通知 |
| cctop | 菜单栏监视会话，跳回终端 |

**所以条目不能只写「在刘海上审批」**，Perch 和 Topnotchers 已经这么写了，会被当重复关掉。
条目里已经改成打「覆盖广度（30+，含中文客户端）+ 每格标注可审批/仅观察」——这是唯一没被占的位置。

## 具体怎么做

1. Fork `jaywcjlove/awesome-mac`
2. 改 `README.md`：在 **`Sharptooth` 之后、`BeardedSpice` 之前**插入 `1-英文条目.txt` 那一行
   （X 排在 S 之后；这一节从 Agent Island 到 Sharptooth 是字母序）
3. 改 `README-zh.md`：同样位置插入 `2-中文条目.txt`
4. 自检：行尾无多余空格、只有一句话、没有 emoji、**没有 `Freeware` 图标**
5. commit message：`Add XIsland to Menu Bar Tools`
6. 开 PR，正文用 `3-PR正文.md`
7. 开完**不要催**，这个仓库合并周期几天到两周

## 为什么不加 `![Freeware][Freeware Icon]`

现在是限时免费，之后 12 美元买断。标 Freeware 是错的，维护者会挑。
同理，PR 里也不要写「我们比 Perch 好」这类比较——在 PR 里打竞品是这类仓库最反感的行为，
只描述自己做了什么、和已有条目的**位置差异**在哪。

## 顺带一个结论：awesome-claude-code 暂时别投

`hesreallyhim/awesome-claude-code`（57k star）的 CONTRIBUTING 明写：

> if your project requires any form of signup or payment, **this is a blocker for reviewing it**

我们领激活码必须注册，正好踩上。而且它只收**网页 issue 表单**，不接受 PR，也不支持 `gh` 命令行。
1 star 的阶段投过去，最好是石沉大海。**等 star 过 100 再说**，或者先让 README 里那段
「How it compares」自己说话。

## 真实收益预期

不要指望合并就来量。一条收录通常带来**每月个位数到几十次**点击。

价值在两点：**永久入口**（帖子会沉，README 不会），
以及**背书**——以后被人问「凭什么用你的」，可以答「在 awesome-mac 的菜单栏工具里」。
