# 掘金 · 分类、标签、发布步骤

## 填什么

| 项 | 值 | 说明 |
|---|---|---|
| 标题 | `1-标题-推荐.txt` | 备选在 `1b-标题-备选.txt` |
| 正文 | `3-正文-粘贴为Markdown.md` | **按 Markdown 粘**，别开纯文本模式 |
| 分类 | **人工智能** | 备选「开发工具」 |
| 标签 | `AI编程` `Claude` `Agent` | 必须选站内已存在的，别现场造词 |
| 摘要 | `2-摘要.txt` | **必须单独填**，不填会截正文开头，卡片很难看 |
| 封面 | `图/xisland-00-封面-英文原图.png` | 16:10，够用 |

## 三条会翻车的地方

**1. 正文里绝对不能有 http 链接。**
掘金的判断逻辑是「技术内容可以带推广，不能是软文带硬广」。正文挂链接 + 一句「欢迎体验」，最容易判推广。
正文末尾已经只留了仓库名（纯文本 `Meteorkid/XIsland`），不要手贱补成链接。

**2. 链接放这两处：**
- 评论区首条（`5-评论区首条.txt`），发布后自己发，然后置顶
- 作者简介：`做 macOS 工具，也写 AI 编程客户端接入的核对笔记。GitHub: Meteorkid`

**3. 摘要别复制正文第一段。** 摘要是卡片预览，要能独立成句。

## 发布后的 30 分钟

1. 自己发评论区首条并置顶
2. 转发到「沸点」，一句话：`把「收到通知」和「能替你批准」分开之后，整个接入矩阵就得重做一遍。`
3. 掘金的推荐量看前 2 小时阅读完成率，所以**别在开头加自我介绍**，正文已经是结论先行
