# 雅思写作：字体、改动标记、详细笔记与生词（2026-11-14）

## 用户要求与实现

用户要求区分字体、特殊标记改动，并给每篇作文添加详细笔记和生词。本次围绕现有对照页实施，未新增数据库表。

- 原文使用无衬线字体，升级版使用 Georgia 等系统衬线字体；尺寸、行高与字距分别设置，无需下载新字体。
- 按每个句对计算词与标点的最长公共子序列，原文替换/删除部分用琥珀底色及虚线，升级版新增/改写部分用绿色底色、加粗和实线。标记表达字面差异，具体改写理由沿用逐句说明，不自动给差异判分。
- 逐句和全文两种模式都显示标记，允许关闭。词序、标点、空白与大小写全部保留；从标记片段重建得到原始字符串。
- 六篇精选各补审题、全段落解析、3–5 个句式/衔接技巧、易错点及 8 个生词/表达，共 48 词。每项含词性、双语语境释义、用法辨析、常用搭配、原句和原创双语例句。具体词条绑定 `segmentIndex`，引用正文时按索引即时读取。
- 公共详情与管理员预览复用 `IeltsLearningNotes`。页面顶部可以直接跳到笔记或生词区；生词卡和技巧说明可用键盘展开，手机不并排挤压。
- 同时校正了既有讲解中不准确的比较级、集合名词一致、`cannot`、倍数基期及论证评价，未改两版作文正文、题干或标题。

教学说明参考 [IELTS 官方评分维度](https://ielts.org/cdn/Guides/ielts-writing-band-descriptors.pdf)。Task 1 展示 Task Achievement / TA，Task 2 展示 Task Response / TR；既有 JSON 仍保留 TR 键，避免结构性迁移。原创示例分档为练习参考，未声称获得官方考官评分。

## 内容协议与自动生成

- `IeltsPairContentSchema.learning` 是可选字段，兼容已发布旧 JSON；精选内容测试要求每篇提供完整字段。
- 校验全段讲解顺序、技巧句索引、生词索引、词条在引用句中的完整匹配及重复项。历史生成内容无扩展字段时展示原有逐句说明，并明确尚未补充生词，不凭空填造。
- 新生成分两阶段：先校验两版作文，再为同一份正文生成笔记。第二阶段失败仅重试笔记，不换作文；完整结果通过引用校验后才返回供写入草稿。
- 所有阶段及重试共用 50 秒截止时间，早于现有反向代理 60 秒超时；笔记不合格不返回不完整草稿。
- 本轮生成验证为模拟接口测试，未再次调用真实 DeepSeek。该双阶段流程的真实模型完成率/耗时尚未实测，不能沿用旧版单阶段成功记录。
