# 小红书内容工作台

管理端入口：`/admin/xiaohongshu`（仅管理员可见，非管理员返回 404）。

## 它解决什么

把「每日一新」或一篇已发布的站内文章，整理成一篇小红书图文笔记草稿：

- 标题 20 字、正文 1000 字的计数和发布前检查
- 3:4 封面 / 正文图片的预览与顺序调整
- 标签、原文链接、草稿 / 待发 / 已发布状态
- 复制标题、正文、标签，或导出 Markdown
- 最近 7 天里，公众号草稿与小红书笔记并排查看

**不包含自动发布。** 小红书开放平台主要面向商家和服务商，普通个人没有官方笔记发布 API；浏览器自动化登录发布存在账号风控风险。最后一步在 App / 创作服务平台手动完成，工作台只记录状态。

## 日常流程

1. 日刊发布后，打开 `/admin/xiaohongshu`，在「近 7 天内容台」点「生成小红书」。
2. 工作台会填入标题、正文、标签和原文链接；先改第一段，把结果放在最前面。
3. 上传或生成图片。第一张就是封面；建议 6–9 张，最多 18 张。3:4、1080×1440，重点内容放在上方约 75%。
4. 看「发布前检查」：红色是阻断项，黄色是提醒项。标题里的「最 / 第一 / 最佳」和正文里的微信号、二维码、外链都会被提示。
5. 点「保存为待发」，或先存草稿。
6. 点「复制文案并打开发布页」：工作台会把标题、正文、标签和图片顺序复制到剪贴板，并打开小红书创作服务平台。
7. 在发布页上传图片、粘贴文案、手动点发布。
8. 回到工作台，把笔记链接粘贴到「小红书笔记链接」，点「标记已发布」记录状态。

**这不是自动发布。** 个人号没有官方笔记发布 API；工作台只负责整理、复制、打开官方页面和记录链接，不会登录账号、不会代替你点发布。发布链接只作记录，不抓取点赞/收藏。

## 发布助手

编辑区底部的「发布助手」提供三个动作：

| 动作 | 作用 |
|---|---|
| 复制文案并打开发布页 | 校验标题/正文/图片和阻断项后，复制发布包并打开 `creator.xiaohongshu.com/publish/publish` |
| 只复制发布包 | 复制标题、正文、标签、图片顺序和发布页地址 |
| 下载 .txt | 把同一份发布包下载到本地，便于离线粘贴 |

「小红书笔记链接」在保存为 `published` 时写入 `published_url`；它不会改变平台上的内容，也不代表平台已审核通过。记录链接的价值是以后能回看“这条笔记对应哪篇站内文章/哪期日刊”。

## 建议内容主线

- AI 工具实测：WorkBuddy、Claude、Codex、建站工具的真实的设置、截图和踩坑
- 独立开发复盘：做站、上线、接单、失败记录
- 申请 / 学习工具：港校申请、雅思、竞赛工具

先用 3–5 篇测试哪条线有搜索和收藏，再决定主赛道。不要照搬「AI 养生」泛流量号；你的可信度来自真实产品和真实使用记录。

## 部署

新增表在 `drizzle/0060_amusing_true_believers.sql`，发布链接列在 `drizzle/0061_bizarre_pestilence.sql`。部署时执行：

```bash
pnpm db:migrate
```

图片上传复用 `/api/blog/upload-image`（R2）；没有配置 R2 时仍可粘贴图片 URL，或用「生成文字封面」后下载到本地手动上传。

标题、正文、标签、图片数量同时受 API 和数据库约束；不要只改前端限制。
