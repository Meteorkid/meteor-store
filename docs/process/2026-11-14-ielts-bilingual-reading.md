# 雅思对照：精读排版与可选中文译文

> 日期：2026-11-14；承接尚未提交的字体、标记、笔记与生词改动。

## 用户要求

进一步优化排版，在每句英文下面添加中文翻译，并允许选择是否显示。

## 完成内容

- 比较区按段落分组，以轻分隔线组织句对，减少逐句圆角大卡片。正文可以选中复制，改写说明用独立按钮展开。
- 阅读模式与中文翻译开关放在第一行；改动标记、关注重点和全篇说明放在第二行。关注维度改成原生选择框，保留功能并收拢六个胶囊按钮。
- 原文仍用无衬线、升级版仍用衬线；减弱背景高亮并取消改写全文式加粗，保留不同颜色和线型。
- 中文翻译默认关闭，开启后显示在对应英文下面。桌面用 CSS Grid 把两侧英文置于同一行、两侧译文置于下一行，使译文顶部对齐；手机按原文/译文、升级版/译文顺序排列。
- 全文模式支持同样的开关；开启后按句插入译文，关闭后恢复英文段落。当前阅读过程中跨模式保留选择；不写账号设置，不承诺跨设备保存。
- 六篇精选共 74 个句对、148 条中文译文。两版分别译各自原句，保留立场、否定、程度、事实与数字，低分版内容错误照原意翻译，纠正仍在笔记里。
- `IeltsSegmentSchema.translationZh` 为可选双字段对象，兼容旧 JSON；新生成协议要求两侧译文完整，否则先重试正文阶段，不返回缺译文的草稿。翻译开关只展示已有文本，不触发模型请求。
- 全无译文的旧内容显示提示；部分句子缺失时逐句提示，不用另一版译文填充。
