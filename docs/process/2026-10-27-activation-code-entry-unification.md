# 软件激活码入口统一

用户要求：只展示一个月、一年、永久三种激活码，隐藏旧邀请码入口，保留历史用户兼容，提交并上线。

## 新用户流程

- 购买或管理员定向赠送后，在账户的“软件激活码与设备”查看激活码。
- 激活码直接填入对应软件的授权设置，网站不要求额外兑换。
- 桌面/手机菜单、账户快捷入口和定价区统一指向 `/account#software-licenses`。定价卡、账户码列表和交付邮件使用一个月、一年、永久的期限文案。
- 价格、SKU、`monthly/annual/lifetime` ID 和历史套餐名称解析不变。单品仍按现有永久买断出售；一个月/一年套餐仍通过 Meteor Pass 获得两款对应软件的码。

## 历史兼容

- `/redeem` 与 `POST /api/invite/redeem` 保留，原有效邀请码的次数、期限和既有授权不变；页面标明历史用途并 noindex。
- `/admin/invite-codes` 隐藏导航但保留直接访问，可查看和显式撤销旧码。旧创建 POST 在管理员、Origin 和限流检查后返回 410，不新增 INV 码，引导使用账号管理赠送激活码。
- 旧帮助文章保留直接 URL 并 noindex，从帮助列表、搜索、推荐、新手路径、Spotlight 和 sitemap 排除。法律条款及历史权益说明保留。
- 在历史兑换页误填软件激活码时，提示在软件设置激活，不提交到旧兑换 API。

## 验证与上线

- 本地工作区完整测试 3393 项通过、20 项跳过，TypeScript 与相关 ESLint 通过。
- 真实隔离 PostgreSQL 覆盖此前发出的 INV 兑换为两软件激活码、重复兑换不增加次数、原授权仍可查询/激活；没有用真实客户的邀请码做验证。
- 本次只改网站入口、文案及旧码创建入口；不迁移数据库、不更换正式签名密钥、不重发 XNook/XIsland 安装包。
- 发布使用独立干净 checkout，不夹带日刊、公告、Pathfinder 等其他未提交工作。生产继续保留原授权服务、历史记录与运行时下载目录。
- 线上需复查三档定价、菜单/账户入口、旧帮助 noindex 与直链、sitemap 排除和服务健康。授权与老码数据库行为由既有服务和隔离回归保证；不为界面验收消耗真实邀请码。
