# 手机管理员入口修复

用户确认手机直达`/zh/admin`可以进入，但找不到界面入口。定位到两层原因：手机隐藏桌面头像菜单，管理链接在手机菜单八个账户链接之后；密码及MFA成功响应缺少`isAdmin`，AuthProvider直接保存响应，因此客户端跳转后管理入口可能缺失，刷新后`/api/auth/me`才补上。

## 修改

- 手机顶栏增加44×44起的“管理”直达按钮，管理员打开菜单后首项为52px高的“管理后台”入口。
- 移除账户区底部重复入口；点击仍关闭菜单并释放滚动锁。游客/普通用户不显示入口。
- 密码登录及两个MFA成功分支增加`emailVerified`、实时计算的`isAdmin`。管理员标记仅用于显示，不进入JWT；服务端鉴权保持不变。

## 验证

新增回归先得到7个预期失败，再修复通过；覆盖管理员/普通用户、MFA成功两分支和失败、手机顶栏可达性、菜单首项及关闭行为。原源码约束更新为同时识别可选链。

隔离本地PostgreSQL中创建合成管理员，经真实登录页面登录后无需刷新即可看到入口；点击菜单首项成功进入后台，滚动锁已释放。320/360/390/768宽度下按钮44×44且无页面横向溢出，1024宽度恢复原桌面账户入口。此为浏览器视口验证，不等于安卓实体手机安装验收。

证据保存在`test-results/mobile-admin-20261031/`。线上发布记录见下文。

## 安卓后续

当前站点已有PWA清单与离线兜底Service Worker。APK可以共用账号和服务端，通过TWA承载优化后的网页；它仍依赖支持该能力的浏览器和网站关联验证。单纯打包不会改变网页布局。独立原生管理客户端属于另一开发范围，尚未创建APK工程、安装SDK或生成安装包。
