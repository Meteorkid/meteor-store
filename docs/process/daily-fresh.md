沿用项目 Node 22、pnpm 与 PostgreSQL 配置。先用指向本地测试库的 `DATABASE_URL` 执行 `pnpm db:migrate`，然后 `pnpm dev`，访问 `/zh/daily` 或 `/en/daily`。后台入口为 `/zh/admin/daily`，仍由 `ADMIN_EMAILS`、已验证账号及当前会话控制。

不要把本地测试数据库的连接串、测试账号或内容带进生产配置。

## 生产调度

调度配置保存在 `deploy/daily.cron`，部署时只替换对应任务，保留备份、证书、Pathfinder等其它任务。使用北京时间、`flock`和`--env-file`，密钥不写入crontab。

- 08:40自动生成并公开，09:10补跑；之后09:40–23:40每小时只补缺失、失败或空栏目。
- 09:30固定一次提醒快照，之后每小时重试至23:30；仍只取09:30前已发布内容，不倒填晚到内容、不重复通知。
- 08:10和14:10同步硕士官网，09:00和15:00检查申请截止提醒。

成功生成但栏目缺失、仍有未暂停草稿或采集失败时返回503，不能把“没产生内容”当作成功。正常无新消息返回空态，后台和日志可区分。旧Pathfinder日报全站广播保持退役。
