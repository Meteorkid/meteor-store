# Ex-Memory 导入与首次体验修复

日期：2026-10-23。状态：本地修复与隔离验收；未提交、未部署、未联系真实用户。

## 用户目标与实现范围

让普通用户能从支持的聊天文件完成导入、创建和第一条模拟对话；网站与应用统一为“基于真实聊天的个人记忆镜像”，明确数据处理边界。将“是否比更强模型直接使用同一文件更省事、更稳定”作为后续真实用户验证问题，不把修复结果宣传成效果优势。

- 网站仍保留现有产品ID、实验室归类、价格和禁售门控。在线试用与付费方案可用性分别说明。
- 首页和Playground以真实使用步骤替换虚构SDK/CLI。中英文产品页、帮助、体验页、隐私说明保持一致；旧前任画廊不再展示。
- 新用户下载明确标为虚构的示例即可了解流程，不强制先完成微信专家导出。
- 没有修改生产环境、用户镜像、真实聊天、研究评测脏文件或并行daily功能。

## 导入与恢复

1. `/api/import/config` 提供支持后缀、大小、协议版本、模型配置能力布尔值，不公开凭据。
2. 展示名称与记录中的目标说话人分开。明确确认处理方式后保存本人草稿，不先用空资料生成。
3. 真实解析、目标消息核对、去重和入库后，才由记录生成人物记忆与运行文件。空文件、坏编码、坏JSON、无目标消息不作为成功。
4. 导入失败保留草稿和界面输入；相同文件重试不重复归档。上传受理响应或轮询丢失时先核对原任务，已完成则直接打开。
5. 导入、恢复和删除使用同镜像锁；未就绪镜像在扣费前拒绝聊天。修复factory漏传owner，确保生成与首次聊天读同一账号目录。
6. 前端GET去重按会话分键。退出/登录清理当前页面状态；响应、JSON读取和网络重试退避均核对会话版本，旧账号响应不能覆盖新列表。
7. 桌面创建页面使用单独布局，修复原“我、钱包、创建”同时出现；手机375px下表单与底部按钮可达。创建入口支持键盘。

## 按记录生成的人物与关系

仅对本轮新增的 `creation_source=chat_import` 路径使用证据模板，分别标注明确事实、有限推断与未知；不得无依据添加恋爱、分手、人格类型或例句。默认阶段为 `source`（依据记录），API、界面与引擎一致。新运行文件如实说明AI模拟身份。旧镜像的原有模板与显式阶段不变，不批量重写用户资料。

## 数据与产品说明

在线托管体验会在网站服务端保存处理后的记录、人物记忆和对话，并向配置的Embedding/LLM服务发送必要内容。本机微信助手的采集/导出发生在用户电脑，不等于确认上传后的整个体验全本地。页面保留常驻AI模拟说明，不承诺“完美还原”、不把生成回复当本人真实言论。
