# 后台概述卡片跳转

用户明确指出后台“概述”数字卡片无法点击进入具体页面。根因是13张卡片均由无链接的div渲染。

## 修改与对应页面

整张卡片改为本地化Link，文字、数字和空白区域均可点击；显示“查看详情”及箭头，保留清晰键盘焦点。手机两列排列，较窄屏仍可完整操作。0条统计也可进入列表。

| 统计 | 目标 |
| --- | --- |
| 文章总数、已发布 | 文章管理 |
| 待审核 | 审核队列 |
| 评论总数、待审核评论 | 评论管理 |
| 待处理举报 | 举报管理，初始pending筛选 |
| 待处理反馈 | 反馈管理 |
| 用户总数 | 账号管理 |
| Pass总计、月付、年付、买断 | 订单与授权 |
| 历史邀请码兑换 | 账号管理中的兑换记录 |

本次接通既有管理模块，没有增加普通用户权限、修改统计口径或重新开放历史邀请码管理入口。
