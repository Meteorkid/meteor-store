# 雅思写作对照 · 交付记录（2026-11-14）

用户要求：做一个专门提升雅思写作的功能——放一篇 5 分水平的作文和一篇 8 分水平的作文，
8 分版是在 5 分版基础上做词汇、句式等优化，左右两边各一篇方便对照学习。
确认过的范围：内容「首批精选 + 后续自动生成」都要；题型覆盖 Task 2、Task 1 学术类、Task 1 书信（G 类）；
**公开可看**（游客也能读，登录后可标记已学 / 收藏）。设计见
`docs/superpowers/specs/2026-11-14-ielts-writing-comparison-design.md`。

## 交付内容

### 内容与数据层

- 内容协议 `src/lib/ielts/types.ts`：一组对照 = 同一篇作文的 5 分档与 8 分档，
  **正文只存逐句对齐的 segments**，两版全文由 `essayParagraphs` 推导；协议强制段落编号从 1 连续、
  每段两版句数一致（左右两栏错位是这一页唯一不能出的错）。
- 精选内容 `src/data/ielts/batch-{a,b,c}.ts` 共 **6 组**：Task 2 四组（观点-教育 / 讨论-科技 /
  问题解决-城市交通 / 利弊-在家办公），Task 1 学术一组（表格题，题干内嵌完整数据），
  Task 1 书信一组（正式投诉信）。每组 9–18 个对齐句对，逐句中英双语说明升级点。
- 合并层 `src/lib/ielts/catalog.ts`：文件精选 + 数据库 `ielts_pairs` 按 slug 合并，
  数据库优先；`hidden` 整体下架、`published` 且有正文整组替换、content 为空只覆盖状态与排序、
  `draft` 不公开、**读库失败退回只用文件内容**。每条规则都有测试。
- 迁移 `0057_giant_annihilus.sql`：只新增 `ielts_pairs`（slug 唯一 + 状态/来源检查）与
  `ielts_progress`（复合主键 `(user_id, pair_slug)`，`studied_at` / `bookmarked_at` 各自可空）两张表，无外键。

### 公开页（学习区里唯一可被收录的页面）

- `/study/ielts` 对照库：按题型与主题筛选，卡片显示两版词数与升级处数，登录后显示已学 / 收藏徽标。
- `/study/ielts/[slug]`：题目 + 左右对照 + 四项评分维度对比 + 可抄走的写法 + 上一组 / 下一组。
  逐句模式点一句看说明，可按升级维度筛选（其余句淡出）；全文模式两栏各成一篇完整文章；
  移动端上下堆叠（并排会让每句折成好几行）。
- 学习状态接口 `/api/ielts/progress`：未登录 401、跨站 403、`X-Ielts-User` 对不上 409、
  限流 30 次/分钟、响应 `no-store`；切换后回读真实状态返回，客户端不做乐观更新。
- 导航：「学习与机会 → 我的学习」新增第 4 个入口；学习区子导航新增「雅思写作」；
  sitemap 收录列表页与每一组详情页（带双语 alternates）。

### 自动生成与后台

- `src/lib/ielts/generator.ts`：DeepSeek（与每日英语同一把 key）生成新对照，
  提示词要求「8 分版是 5 分版的升级、逐句对齐、词数达标」，zod 校验 + 词数校验兜底，
  不合法重试（最多 3 次）再报错；模型输出的升级维度同义词（vocabulary → lexis 等）会先归一化。
- `/admin/ielts` + `/api/admin/ielts`：列表（含草稿 / 已下架 / 来自文件精选）、
  生成新对照、发布、下架、恢复文件版本、删除。生成动作单独限流 5 次/分钟；
  非管理员一律 404；写操作记审计日志 `ielts.generate|publish|hide|restore|delete`。

### 隔离浏览器验收

环境：本机 PostgreSQL 18 独立库 `meteor_ielts_verify`（与生产无连接）、生产构建
`next start` 于 `127.0.0.1:3186`、5 个专用测试账号。Playwright 实测：

- 公开页：库页 6 组、按题型筛选（Task 1 书信 → 1 组）、详情页逐句展开说明、全文模式两栏、
  四项评分维度与「可以直接抄走的写法」、未登录显示登录入口、英文页可读、390px 无横向溢出。
- 学习状态：标记已学与收藏 → 刷新仍在 → 库页卡片出现徽标；**第二个账号读不到第一个账号的标记**。
- 后台：下架「科技让人更近还是更远」→ 公开库 6 → 5 组且详情页 404；恢复文件版本 → 回到 6 组。
- **生成实测**（真实调用 DeepSeek）：成功一次产出 293 / 302 词、18 处升级、耗时 19.4 秒；
  保存为草稿（数据库 0 行 → 1 行）→ 点发布 → 公开库出现第 7 组。
  另一轮生成因 5 分版只有 183 词被校验挡下，后台显示
  「雅思对照生成失败：5 分版词数不合适（183）」——失败路径可读、不崩。
