# 2026-10-17 全站二级导航与登录回跳

状态：已提交、部署并完成下述生产复验。应用提交为 `56d5159`。部署前审计与新版验收分别记录，时间均为北京时间。

## 设计与范围

目标是让现有产品、日刊、学习机会和内容从全站导航可达，并兼顾鼠标、键盘、触屏与短视口。参考 [Apple 官网](https://www.apple.com/) 的产品分类与工具入口，以及 [Vercel 官网](https://vercel.com/) 的栏目分组；采用适合本站的五组结构，保留暗色材质、现有字阶与减少动态效果设置。

| 一级导航 | 二级组织 | 数据边界 |
| --- | --- | --- |
| 产品 | 主线产品、免费工具、探索更多 | 保留全部产品；实验室使用现有 `/products#lab`；定价遵循 `SHOW_PRICING` |
| 每日一新 | 每天读一点、关注新动态、发现新机会 | 七个日刊从轻量栏目配置推导，使用 `/daily?view=all#栏目` |
| 学习与机会 | 学习方向、机会与申请、继续发现 | Pathfinder 原有页面与独立 `/masters` 日历 |
| 内容 | 产品与技术、人文、浏览与创作 | 六个博客分区仍由 `blog-sections.ts` 唯一定义 |
| 帮助 | 认识这里、联系与反馈 | 帮助中心、故事、支持作者、联系及反馈 |

每组有真实总览链接与 2–3 列二级入口；启用定价时共 40 个入口。Logo 返回首页，搜索、通知、语言和账号作为工具区。账号入口同时覆盖桌面与移动端；管理员只提供总入口，不复制后台深链接。

主要改动：

- `src/data/header-navigation.ts` 统一导航数据与当前页判断；带 query/hash 的深链不因 pathname 相同而同时标为当前页。
- `src/lib/daily/channels.ts` 提供无 Zod、数据库依赖的栏目常量，`types.ts` 重导出以兼容原消费者。
- `DailyHub` 的 `view=all` 临时显示全部栏目，旧空关注也有锚点；切回“我关注的”移除该参数、保留日期，不修改个人偏好。翻日期及回今天保留全栏目视图。
- 六个个人页面改用本地化登录地址并携带 `next`：账户、订单、兑换、投稿、我的投稿、博客收藏。投稿编辑保留受限的文章 ID 与 `admin=1`；实际权限仍在页面和 API 校验，回跳白名单不开放任意 URL。
- 修复本地实测的跨组失焦吞掉第一次点击、`/` 搜索与菜单焦点争抢；短视口下拉面板限高并可滚动。
- 开发环境静态资源改为 `no-store`，避免修改后继续使用旧交互代码；生产静态缓存规则保持不变。
