# 产品展示顺序实施计划

> 日期：2026-08-24

## 目标

实现独立的产品展示顺序：首页展示前六项，产品总页按完整顺序展示，业务数据源的原始顺序保持不变。

## 步骤

1. 新增产品展示顺序测试，覆盖完整顺序、唯一性、产品覆盖和缺失配置报错。
2. 新增 `src/data/product-order.ts`，提供展示顺序与非原地排序函数。
3. 让首页精选顺序从统一展示顺序的前六项派生，并更新现有测试。
4. 让产品总页在分类筛选前应用统一展示顺序。
5. 运行相关 Vitest、TypeScript 检查和格式差异检查。

## 边界

- 不重排 `src/data/products.ts`。
- 不修改后台、支付、邀请码或 Footer 的产品顺序。
- 不触碰工作区现有的其他未提交改动。
