# 全站双主题选择

## 目标

保留“经典紫夜”和“星云星海”两套首页，并把选择提升为全站视觉主题。两套都固定暗色：经典版以紫色流体、流光和科技网格为主；星云版以银蓝星云、三维视角和留白为主。

## 偏好来源

- 游客：写入 `meteor:theme:guest:v1`，同时写一年有效的非敏感 `meteor-theme` cookie，用于服务端首帧选择正确主题。
- 登录用户：`users.theme_preference` 保存 `classic` / `nebula`；`GET/PATCH /api/account/appearance` 读取和更新，带账号 ID 校验，避免其他标签页换号后旧表单覆盖新账号。
- 首次登录尚无账号主题时，把本机已选主题带入账号。退出登录后恢复本机游客主题，避免两个账号共用浏览器时互相覆盖。
- 本机没有任何游客主题时，退出登录或首次建立账号偏好都回退到默认星云主题，不继承上一个账号颜色。
- 新设备登录后由账号主题覆盖默认值并回写 cookie；此后刷新由服务端直接输出正确主题，减少闪烁。

## 页面行为

- 首页根据主题在经典紫色 Hero 与星云 Hero 之间切换；导航、搜索、接入真实产品统计与所有入口继续共用。
- 星云主题使用三维相机、星光、人海、自绘字形与体积星云；经典主题复用紫色 Aurora、HeroCanvas、流光标题和原首页信息结构。
- Header、语义颜色、页面大气背景、选择色、滚动条与 HeroCanvas 粒子色随主题变化。编辑、表单、支付、管理后台继续使用同一套暗色可读性基线。
- 星云主题把 Tailwind 的 violet / purple / pink / indigo 色阶映射为冷蓝银色阶，因此产品卡片、学习路径、帮助中心、博客、登录按钮与表单焦点不需要逐页复制分支；红、绿、琥珀等状态色保持原语义。
- `min-h-screen bg-black` 页面外壳统一换成带冷色云气的 `--background`，`.glass` / `.glass-card` 使用主题玻璃色，品牌标志、弹窗、返回顶部、帮助星场、流星和星图也读取主题变量。
- 桌面 Header 有主题快捷切换；手机菜单与账号页提供带预览的完整选择器。
- 两套主题均不跟随系统深浅色，`data-theme` 只承载暗色视觉分支。

## 数据与部署

`0055` 只新增 `users.theme_preference text`，不改历史主题。正式部署顺序必须是先迁移、再上新代码；当前只完成本地预览和临时数据库验证，尚未提交或部署。

## 验收边界

本地临时 PostgreSQL 上实测登录、读取空主题、保存经典主题、回读、跨账号写入 409。真实浏览器验证两套中英文首页、产品、日刊、学习、博客、帮助、登录、法律页与手机菜单；星云主题在这些页面统一为蓝银色阶，经典主题仍保留紫色。375px 无横向溢出，生产只读数据库连接下的构建通过。临时数据库和 token 已清理；生产迁移与真实账号跨设备同步仍需上线后验证。
