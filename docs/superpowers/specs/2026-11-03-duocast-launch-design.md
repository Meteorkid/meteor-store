# DuoCast 网站上架

用户要求将 GitHub 新产品上线网站。唯一新增公开项目为 `Meteorkid/duocast`，已核实正式发布 v0.1.0，仅含 macOS 14.2+ / Apple Silicon ZIP。官网采用已有产品页和实验室结构，不调整首页展示、既有价格或账户流程。

## 展示与获取

- DuoCast 归为免费 utility / lab，追加到产品与实验室展示顺序末尾，首页既有内容和主线顺序保持一致。
- 中英产品页说明系统音频/本地文件、最多三路、独立音量/延迟/EQ、按App采集与设备记忆。保留未公证、两副蓝牙不保证同时播放及Windows暂无安装包的实际边界，不称MIT或开源授权。
- 匿名获取固定 `macos-arm64` 下载，通过现有私有R2及5分钟预签名路径；上传仅新增对象并完整回读校验，不覆盖旧发布文件。
- 产品页提供DuoCast自己的GitHub与双语安装指南入口。安装指南用系统设置的安全例外流程，不要求全局关闭Gatekeeper。
- 封面基于真实截图分层重绘三个控件：A音量、B延迟、A一个EQ频段；C保留等待设备。生成1280×800静音操作短片及清晰静态回退，沿用入屏播放/离屏释放/减少动态设置。

## 兼容与发布边界

- 最初线上基线为 `4242e74`。执行期间另一发布已将限免、全产品GitHub入口和博客译文支持上线至 `9762298`；本次衔接新的已上线基线，保留这些变化且不重复执行其数据库迁移。原工作区与分支保留。
- 生产Pass当前保留历史12款展开行为；本次仅排除新增DuoCast，避免将独立免费工具包装为新的付费权益。显式免费入库仍保留单品记录，旧用户权益不收回。
- 将已生效的TLS webroot修复同步进发布源码，避免部署覆盖证书验证入口。无需数据库迁移，不启用新的自动同步或定时任务。
- 产品页、搜索、sitemap从既有产品数据生成；产品列表标题去掉写死的12，播放回归从封面配置推导数量。

核对官方包版本/大小/SHA/架构及签名；运行目录、下载、授权、帮助/搜索/SEO相关回归和完整测试、构建；本地桌面与手机模拟检查导航/封面/下载交互，生产再验证真实匿名下载完整性、HTTPS、健康与媒体资源。应用声音效果没有用真实耳机重新实测。
