# Tollow Free / Pro 权益与真实统计设计

> 日期：2026-08-24
> 状态：已确认

## 背景

Tollow 当前配置了免费 Basic 与 ¥15/月 Pro，但商业系统只按 `productId=tollow` 判定访问权。免费入库、付费订单、邀请码和 Meteor Pass 最终都会渲染同一个应用，并启动同一套进度、练习记录和收藏同步。产品页宣称的“7 天数据”“高级追踪”“API 接入”等权益没有对应的服务端权限边界。

应用本体已经具备完整打字练习、内置书库、本地进度、基础 WPM/准确率、文本收藏与笔记，以及数据库支持的账号同步。现有分析路由展示通用页面访问和性能指标，其中趋势数据由随机数生成，不能作为付费能力交付。账户级 JSON 导出已经包含 Tollow 数据，属于用户数据可携权，不应设置付费门槛。

## 目标

- Tollow 调整为 Free ¥0 与 Pro ¥29 买断，Free 登录后免费入库。
- 使用稳定的套餐标识判定权益，不依赖可变的中文名或展示文案。
- Free 保留完整本地练习体验，但不读写 Tollow 云端数据。
- Pro、有效 Meteor Pass、管理员和 Pro 邀请码获得账号云同步、跨设备进度、收藏笔记同步、真实历史统计、CSV 导出和打印报告。
- 历史 Tollow Pro 用户统一升级为新的永久 Pro，不追溯收回权益。
- 所有付费能力在服务端强制校验，不能只隐藏前端入口。
- 保持现有全账户 JSON 导出对所有登录用户开放。

## 非目标

- 不为其他单品同时重构完整的套餐授权体系。
- 不增加 Tollow 订阅、自动续费、用量额度或 API 开放平台。
- 不把 Free 本地数据上传到服务器，也不提供匿名 Free 模式。
- 不在本期提供收藏与笔记的单独 CSV；它们继续包含在全账户 JSON 导出中。
- 不引入 PDF 生成服务。学习报告通过浏览器打印并可另存 PDF。

## 产品权益

### Free

- 完整打字练习
- 内置书库
- 上传个人文档
- 当前浏览器内的本地进度
- 基础 WPM、准确率与错误反馈
- 本地收藏、笔记与标签

Free 必须登录并免费入库后使用。它不会启动进度、练习记录或收藏的云同步，也不能访问云端统计、CSV 导出和打印学习报告。

个人文档上传沿用现有能力边界。TXT、DOC/DOCX、Markdown 和 HTML 等可提取文本；PDF 当前只有占位内容，EPUB/ODT 为简化解析。本次分档不扩展文件解析能力，产品文案不得宣称完整支持这些格式。

### Pro ¥29 买断

- Free 全部功能
- 阅读进度与练习记录云同步
- 跨设备恢复
- 收藏、笔记与标签云同步
- 真实完整历史趋势
- 高级练习统计
- 练习记录 CSV 导出
- 可打印学习报告

Pro 是永久单品授权，与现有单品订单规则一致，没有到期时间。

## 稳定套餐标识

### 数据模型

在 `orders` 增加可空的 `plan_id` 文本列。它保存产品配置中的稳定套餐 `id`，Tollow 使用 `free` 与 `pro`。字段保持可空，以兼容其他历史单品订单和滚动部署。

新订单和免费入库必须由服务端根据产品配置解析套餐，并写入 `plan_id`。客户端可以提交 `planId` 作为选择，但服务端仍以 `productId + planId` 查找真实套餐和价格，不能信任客户端传入的名称或金额。为兼容部署期间的旧客户端，支付接口可暂时接受 `planName` 回退匹配；成功解析后仍写稳定 `plan_id`。

`Entitlement` 增加单品 `planId`。Pass 自身的 `passPlanId` 继续表示月付、年付或买断周期，两者不复用，避免再次混淆套餐和计费周期。

### 迁移与历史兼容

迁移只做可回滚的增量修改：

1. 增加可空 `orders.plan_id`。
2. 将 Tollow 历史 `plan_name` 为 `Pro` 的已支付订单回填为 `pro`。
3. 将 Tollow 历史 `Basic` 或 `Free` 已支付订单回填为 `free`。
4. 其他产品历史订单保持 `NULL`，读取时沿用既有行为。

读取端保留 Tollow 旧订单回退规则：`plan_id` 为空时，`planName=Pro` 视为 Pro，其余已知免费名称视为 Free。该兼容逻辑防止迁移遗漏或滚动部署期间历史用户被降级。

邀请记录已经保存 `invite_codes.plan_id`。Tollow 邀请码使用 `free/pro`；历史 Tollow 邀请码同样按 `planName` 回退。授权码撤销继续收回邀请码和已交付订单的访问权。

## 权益解析

新增服务端统一入口 `getTollowAccess(userId, email)`，返回：

```ts
type TollowAccess = {
  level: 'none' | 'free' | 'pro';
  source: 'none' | 'order' | 'invite' | 'pass' | 'admin';
};
```

权限强度为 `none < free < pro`。解析所有有效来源后取最高等级，而不是简单取最新一条：

- 管理员：Pro。
- 有效 Meteor Pass：Pro。
- Tollow Pro 订单或 `planId=pro` 邀请码：Pro。
- Tollow Free 入库订单或 Free 邀请码：Free。
- 无有效来源：none。

直接 Free 订单不能遮住有效 Pass；后来的 Free 授权也不能把历史 Pro 降级。Pass 过期后，如果用户仍有 Free 入库，则降回 Free；若有永久 Tollow Pro，则继续为 Pro。

应用服务端挂载页用该结果决定是否渲染 Tollow，并把 `free/pro` 作为可信属性传给 `TollowApp`。`none` 继续显示购买或免费入库引导。

## 服务端权限边界

新增可复用的 `requireTollowPro()`，从 session 和数据库权益解析权限。下列接口必须在任何业务查询或写入前调用：

- `/api/tollow/progress`
- `/api/tollow/sessions`
- `/api/tollow/import`
- `/api/tollow/favorites`
- `/api/tollow/favorites/[id]`
- 新增 `/api/tollow/analytics`
- 新增 `/api/tollow/export/sessions.csv`

未登录返回 401。已登录但不是 Pro 返回 403，并使用稳定错误码：

```json
{ "error": "需要 Tollow Pro", "code": "TOLLOW_PRO_REQUIRED" }
```

权限判断不得接收客户端提供的套餐等级。数据库或授权查询失败时 fail closed，不放行 Pro 接口。

## 客户端模式

`TollowApp` 接收服务端传入的 `accessLevel`：

- Free：配置账号隔离的本地存储，但不启动 `startTollowAccountSync()` 和收藏云同步。收藏服务进入显式 `local` 模式，列表只读本地缓存；新增、编辑、删除更新本地缓存并保留本地 outbox，但 `flush()` 在该模式下直接返回，不能请求 `/api/tollow/*`。
- Pro：沿用现有离线优先同步、远端合并、重试和账号隔离行为。

从 Free 升级 Pro 后，首次进入应用沿用现有导入流程，将该账号本地进度和练习记录上传并合并到云端；收藏服务切换为云端模式后冲刷 Free 期间保留的本地 outbox。退出账号或切换账号时继续释放对应命名空间，不能跨账号读取。

分析导航对两种等级都可见。Free 打开后看到 Pro 权益说明、¥29 买断价格和升级入口；页面不调用统计接口。基础 WPM 和准确率继续在练习界面即时显示，不属于高级分析门槛。

## 真实统计

### 接口

新增 `GET /api/tollow/analytics?range=7d|30d|90d|all&timeZone=<IANA>`。默认 `30d`。范围和 IANA 时区必须校验；非法输入返回 400。

统计只读取当前 session 用户的 `tollow_practice_sessions`。服务层在数据库中完成聚合，避免把全部历史记录传给浏览器。响应包含：

- `summary`：所选范围内的总练习时长、总字数、练习天数、平均/最佳 WPM、平均准确率、总错误数，以及不受范围截断的当前连续天数和历史最长连续天数。
- `trend`：按用户时区归属的时间桶、练习时长、字数、加权平均 WPM、加权平均准确率。`7d/30d/90d` 使用日桶，`all` 使用月桶，避免多年数据生成不可读的超长折线。
- `books`：书籍标题、练习次数、时长、字数，按练习时长降序。
- `recentSessions`：最近练习时间、书籍、时长、字数、WPM、准确率、错误数，限制合理条数供页面和报告展示。
- `range`、`timeZone` 与 `generatedAt`。

没有数据时返回全零汇总和空数组，不生成模拟值。WPM 按练习时长加权，准确率按输入字数加权；分母为零时返回 0。连续天数按用户时区的实际练习日期计算。

### 页面

用 Tollow 专用分析组件替换当前随机数据仪表盘：

1. 顶部显示标题、`7 天 / 30 天 / 90 天 / 全部`筛选和导出操作。
2. 汇总卡展示练习时长、总字数、练习天数、连续天数、平均/最佳 WPM、准确率和错误数。
3. 使用轻量 SVG 绘制 WPM/准确率趋势和每日练习量，不新增图表依赖。
4. 展示书籍练习分布和最近练习表格。
5. 加载失败显示可重试错误；403 切换为升级页；空数据提供开始练习入口。

不再初始化或读取通用 `analyticsService`，也不回退到 `Math.random()` 数据。原随机仪表盘停止被路由引用；只删除与替换直接相关的死组件，不扩展到无关监控服务重构。

## Pro 导出

### 练习记录 CSV

新增 `GET /api/tollow/export/sessions.csv`，仅 Pro 可用，默认导出当前用户全部云端练习记录。列为：

- 开始时间
- 结束时间
- 书籍
- 练习时长（秒）
- 输入字数
- WPM
- 准确率
- 错误数

响应使用 UTF-8 BOM、`text/csv; charset=utf-8` 和安全文件名。所有字段按 RFC 4180 规则转义；以 `=、+、-、@` 开头的用户可控文本在导出时中和，避免电子表格公式注入。接口保留合理限流，数据库按时间顺序读取。

### 打印学习报告

分析页面根据当前筛选范围的同一份真实统计响应生成打印布局，包含报告范围、生成时间、汇总指标、趋势、书籍分布和最近记录。点击“打印学习报告”调用浏览器打印，打印样式隐藏导航和交互控件，用户可在系统打印框中另存 PDF。

报告不创建公开 URL，不在服务器保存副本，也不新增 PDF 生成依赖。

### 全账户数据导出

现有 `/api/auth/export` 保持原权限与内容，对所有登录用户开放。它继续导出账户、商业、内容、活动、安全信息和现存的 Tollow 云端数据。Tollow Pro 判断不得加入该接口。

## 定价与升级

`products.ts` 中 Tollow 定价调整为：

- `free`：¥0，权益使用本设计的 Free 文案。
- `pro`：¥29，买断，无月付单位，权益使用本设计的 Pro 文案。

Free 卡继续调用 `/api/claim`；Pro 卡走现有支付流程，并传稳定 `planId=pro`。已经拥有 Free 的用户仍可购买 Pro。免费入库的幂等查询发现任何 Tollow 已支付订单时返回已拥有；它不能新增 Free 订单覆盖 Pro。

升级入口统一指向 Tollow 产品页定价锚点。支付成功后的下一次服务端渲染即可解析为 Pro，不依赖客户端缓存套餐状态。

## 错误处理与安全

- 401、403、400、429 和 5xx 保持可区分，客户端只对网络错误、429 和 5xx提供重试。
- 403 不把本地 Free 数据清空，也不尝试重复同步。
- 权限失效或 Pass 到期时，后续 Pro API 立即拒绝；已在浏览器本地的数据仍属于用户，不删除。
- CSV 只查询 session 用户的数据，文件名不含邮箱等个人信息。
- 分析与导出响应不缓存为公共 CDN 内容，使用私有或 `no-store` 缓存策略。
- 服务端不信任客户端的 `accessLevel`、价格、套餐名称或用户 ID。

## 测试

### 权益与商业流程

- 新 Free 入库写 `planId=free`，新 Pro 支付写 `planId=pro`。
- 历史 `Pro` 订单在 `plan_id` 为空时仍解析为永久 Pro。
- 历史 Basic/Free 解析为 Free。
- 多来源取最高等级：Free + Pro、Free + Pass、过期 Pass + Free、Pro + 后来 Free。
- 管理员、有效 Pass、Pro 邀请码均解析为 Pro；撤销授权码或 Pass 到期后正确降级。
- 产品定价合同固定为 Free ¥0 与 Pro ¥29 买断。

### API 与同步

- 所有 Tollow 云端、统计和 CSV 接口：未登录 401、Free 403、Pro 正常。
- 403 在业务数据库读写前返回。
- Free 模式不调用任何 `/api/tollow/*`，收藏和练习仍写入账号本地存储；收藏 outbox 仅保存在本地并等待将来升级。
- Pro 保持现有进度、记录、收藏同步、离线队列和首次本地导入能力。

### 统计与导出

- 各时间范围、空数据、跨日、用户时区和连续天数。
- 平均/最佳 WPM、准确率、时长、字数、错误数和书籍聚合均来自固定夹具。
- 分析页面不引用随机数仪表盘，加载、空态、错误、Free 升级态正确。
- CSV 包含 BOM、稳定列顺序、逗号/引号/换行转义和公式注入防护。
- 打印报告只使用当前真实统计响应，并包含打印样式。
- `/api/auth/export` 继续对普通登录用户开放且包含 Tollow 数据。

### 验证命令

- Tollow 权益、API、同步、统计和导出聚焦测试。
- 完整 Vitest。
- TypeScript `tsc --noEmit`。

- Next.js 生产构建。

## 部署与回滚

先执行只增加字段与回填数据的数据库迁移，再部署应用代码。应用读取端兼容 `plan_id=NULL`，因此滚动部署期间新旧实例都能工作。回滚应用时保留 `plan_id` 列与回填数据；旧版本会忽略该字段。若新统计或导出接口发生问题，可单独回滚路由和页面，不影响已有练习与同步数据。

工作区当前存在 Pathfinder 对 `src/lib/db/schema.ts` 的未提交修改。实施时只在 `orders` 定义附近追加 `planId`，生成迁移前核对 diff，提交时仅暂存 Tollow 相关片段和文件，避免带入其他任务改动。
