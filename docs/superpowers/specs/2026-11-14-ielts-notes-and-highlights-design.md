# 雅思对照精读增强

## 范围

沿用现有左右句对和两种阅读模式，落实用户要求的字体区分、改动标记、逐篇笔记及生词。继续公开阅读，复用管理员预览和现有账号学习状态。

## 设计决定

1. 原文为无衬线、升级版为衬线；词级差异使用两种底色和两种下划线，不单靠颜色传达含义。可关闭标记，全文也能查看差异。
2. 差异由正文计算，不另存一份富文本或人工 HTML。按词/标点对齐并保留原始字符，避免录入修改导致标记错位。
3. `learning` JSON 扩展记录审题、逐段讲解、具体句式技巧、易错提醒、生词卡。技巧和生词绑定句索引；直接引用正文而非复制来源句。
4. 六篇现有精选逐篇补充。新生成增加笔记阶段，未通过引用校验时不给出可保存结果；旧内容兼容且不伪造新增讲解。
5. 文字内容无外部字体依赖，无新表、无生产数据迁移。公开与管理员预览共用阅读组件。
6. 后续用户明确要求的双语阅读：句对新增可选 `translationZh.low/high`。两版分别翻译，开关默认关闭，逐句/全文切换保留当次选择；旧内容缺译文明确提示。新生成要求两侧完整，开关不调用外部翻译。
7. 比较区按段落组织，以轻分隔线代替大卡片；英文与中文视觉层次分开。桌面两侧译文顶边对齐，手机每版英文与译文相邻。说明改为独立按钮，正文可选中复制。

## 验收目标

两版字体可辨；词级新增、删除、标点和大小写差异清晰；切换标记前后正文相同；六篇全覆盖且各有8词；词条原句可核对；中英、390px、键盘和减少动画可用；历史 JSON 与私有预览权限不回归。
