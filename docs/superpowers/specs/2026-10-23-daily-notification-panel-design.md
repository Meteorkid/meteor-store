# 每日内容公告面板与账号自定义

状态：用户已确认右上角公告面板展示具体每日内容，并选择“跟随账号跨设备保存”。本轮按此方案实现并本地验收，提交和生产迁移/部署另行确认。

## 用户体验

- 现有铃铛面板直接展示今日七个日刊栏目的内容，不再只有“每日一新”入口。
- 英语默认3个单词/表达及释义，可展开例句和翻译；论文/AI/活动/开源/竞赛/实习默认各1条标题、简短摘要及已存在的关键日期/地点。链接进入对应日期和栏目，原文保留安全外链。
- “自定义”支持选择/隐藏栏目、上移下移排序、每栏最多1/3/5条（开源为1条）、紧凑/详细、英语释义/例句/翻译、其他栏目的摘要/来源/日期开关，以及隐藏无内容栏目。
- 登录设置跨设备保存；游客可阅读且设置只存本机。默认设置继承已有关注栏目（没有设置则显示全部七栏），但修改公告面板不会改变日刊关注或提醒开关；明确空选保持为空。
- 系统公告、硕士申请提醒及管理员告警保留原独立流程。面板刷新内容不重复点亮09:30提醒红点，不改变提醒快照或自动发布任务。
- 展示日期/更新时间、加载失败重试、未发布/无新增/获取失败的区别；无内容可回看最近有内容期次，不能把旧内容标成今日。
- 设置编辑有取消/保存；失败保留草稿。跨设备同时保存时检测版本冲突，提示重新加载，不静默覆盖另一设备设置。

## 数据与兼容

- 独立公共轻量预览接口从既有`getDailyEditions(today)`读取，沿用公开过滤及当天关闭岗位/已开赛赛事过滤，显式白名单裁剪DTO。英语不带passage/questions，论文不带originalAbstract；每栏最多5条，开源1条，响应有明确大小边界。
- 预览与`/api/daily/reminder`分离；后者继续只负责09:30成员快照和未读。公开预览不混入身份、私人提醒或偏好。
- 给`daily_preferences`新增可空`panel_settings` JSONB和`panel_updated_at`文本列；不回填/改写已有channels/reminders。原日刊偏好API仍只读写原字段，不扩大原strict响应合同。
- 独立面板设置GET/PUT接口：登录鉴权、owner响应及`X-Daily-User`写入校验、Origin、限流、请求长度、strict Zod验证、no-store；以panel_updated_at做条件更新，首次保存用仅插入/条件更新避免覆盖。
- 账户导出包含面板设置；注销既有daily_preferences整行删除自动覆盖。迁移为新增可空列；回滚旧应用时保留新列，不删除用户新设置。
- 本地生成正式迁移文件并在独立PostgreSQL验证；本轮不操作生产数据库。

## 客户端

- 内容组件仅打开铃铛时加载；桌面/手机两实例共享请求缓存，避免每个Header重复拉取。
- 打开、重新聚焦和跨北京时间日期时刷新；关闭/隐藏时不持续拉大内容。请求超时、失败可重试；晚到刊目在下一次刷新显示。
- 账号设置按owner隔离，退出/换号撤下旧设置和草稿，忽略迟到响应；游客设置不自动覆盖账号设置。storage不可用可继续阅读，保存失败有明确提示。
- 移动端面板须完整落在视口内、内部可滚动；Esc/外点关闭与焦点恢复、Header弹层互斥继续有效，不新增嵌套焦点陷阱。

## 实现分工与验收

1. 服务端/协议/迁移：轻量预览、设置持久化和并发，测试隔离/无草稿泄漏/内容裁剪/迁移兼容。
2. 客户端共享状态：按需请求、身份/版本/日期/缓存和本机降级，测试双铃铛去重、乱序请求及换号。
3. 公告UI与自定义：卡片、英语展开、设置表单、响应式位置和键盘，真实浏览器验收中英375/768/1280。
4. 全仓类型/测试/构建，独立PG的A/B账号及两个浏览器会话验证云端保存、版本冲突与旧日刊偏好保存不覆盖面板设置；明确生产迁移/部署未执行。

范围：不新增内容来源、TTS/词典、自动背词计划或新消息渠道，不复制日刊全文进公告表，不要求用户手工发刊。
