# 在线体验 UI 质量提升设计

## 背景

Meteor Store 的在线体验已经采用独立全屏页面，但 WebGL Fluid、Chakra Visualizer、Tollow、Ex-Memory 与 Skeleton Anatomy 的交互成熟度不一致。本轮不统一产品皮肤，而是把已完成的桌面端与移动端 UI Review 转化为可验证的实现标准。

## 目标

- 用户进入页面后能在首屏找到最主要的操作。
- 移动端控制不会遮挡主要内容，所有触控目标不小于 44px。
- 摄像头权限只由明确点击触发，并提供可恢复的失败路径。
- 加载、离线、空状态与错误状态可读且可操作。
- 键盘、读屏和减少动态效果用户可以完整使用核心流程。
- 全屏页面保留各自品牌语言，不显示商城页头页尾或嵌入式卡片边界。

## 共同质量底线

1. 试用路由输出产品专属浏览器标题，并继承商城当前语言。
2. 主要按钮、图标按钮和移动导航触控区域至少 44×44px。
3. 摄像头入口必须是明确按钮；权限失败时保留重试与系统设置说明。
4. 离线状态必须提供重试或恢复动作，不能只显示告警。
5. 加载状态使用产品自己的品牌材质，并在当前背景上保持足够对比度。
6. `prefers-reduced-motion: reduce` 同时停止循环动画和位移动画，保留必要的颜色或透明度反馈。
7. 全屏体验不显示商城导航；返回入口只在不干扰产品主操作时提供。

## WebGL Fluid

### 结构

- 桌面端保留右上角控制入口，默认收起控制面板。
- 移动端使用 44px 浮动按钮打开底部面板，面板不超过安全视口高度并可滚动。
- 常用区只放摄像头、背景/颜色、质量和暂停；模拟参数放入“高级设置”。
- 移除 dat.GUI 默认黑色矩形、蓝色滑块与过小文字，使用流体产品自己的半透明深色材质。
- 全屏容器不保留圆角或卡片阴影。

### 交互

- 面板支持按钮、遮罩和 Escape 关闭；打开后焦点进入面板，关闭后回到触发按钮。
- 摄像头由按钮直接触发，不在初始化或面板展开时自动请求。
- 降低动态效果时隐藏装饰动画，并让面板无位移切换。

## Chakra Visualizer

### 首屏

- “启动摄像头”紧跟标题与一句操作说明，成为首要动作。
- 手势教学和忍术列表降为次级内容；统计压缩成一行或在移动端隐藏非必要项。
- 数量文案从真实忍术数据派生，避免固定显示“8 jutsu”。
- 移动端减少人物、粒子与光效的层级和透明度，保证按钮与说明清晰。

### 状态

- 摄像头未启动、授权中、已启动、权限拒绝均有明确文案和重试动作。
- 辅助文字提高对比度；摄像头仍只由用户点击触发。

## Tollow

### 品牌保持

保留纸张、衬线字体和暖色体系，不套用 Meteor Store 暗色设计。

### 修复

- 加载状态改用暖纸背景上的深色文字和低干扰进度指示，消除不可见和亮色闪屏。
- 移动端补充底部导航或折叠菜单，覆盖书库、练习、分析与个人入口；不再简单隐藏功能。
- 导航项使用当前语言的具体名称，图标按钮提供可访问名称。
- 产品截图更新不属于本轮代码实现，作为发布后的内容任务记录。

## Ex-Memory

### 在线模式

- 隐藏 macOS 交通灯和假桌面标题栏，只保留产品身份。
- 全宽橙色离线条改为右上角紧凑状态提示，附带“重试”。
- “立即创建”切换为现有紫色交互体系，搜索提示和辅助文字达到可读对比度。
- 空状态改成“导入记录 → 创建镜像”的两步引导，明确下一步。
- 为星空、粒子、流星与其他全屏循环效果统一补齐减少动态效果覆盖。

### 边界

在线模式的重试只恢复网络/API 状态，不清除用户本地输入或任务；桌面打包模式仍可保留窗口装饰。

## Skeleton Anatomy

- 移动抽屉提供显式关闭按钮、遮罩关闭、Escape 和焦点回归。
- 骨骼列表改为语义按钮，支持 Enter/Space、键盘焦点和 `aria-pressed`/当前项状态。
- 所有纯图标按钮补 `aria-label`，点击区域至少 44px。
- 未选择骨骼时折叠右侧详情区，把空间还给 3D 画布。
- 缩小选中骨骼的橙色光晕，使其表达精确定位而非装饰爆发。

## 性能与实现边界

- 优先用 CSS 媒体查询和现有状态管理，不新增重型 UI 或动画依赖。
- 只对按需打开的面板增加状态，不扩大客户端组件边界。
- 动画只操作 `transform` 和 `opacity`；频繁操作不使用长动画。
- 保留 WebGL/Three.js 渲染路径，不在本轮修改流体、手势识别或骨骼模型算法。

## 测试与验收

- 为结构性要求增加源码或组件测试：入口位置、真实数量、语义按钮、移动导航、离线重试、减少动态效果。
- 运行 TypeScript、ESLint、现有应用测试与生产构建。
- 在 1280×720 与 390×844 视口分别检查五个项目：首屏主操作、面板开关、键盘焦点、加载/离线状态和无遮挡。
- 摄像头验证包含允许与拒绝两条路径；浏览器不具备真实摄像头时至少验证权限请求由点击触发、错误可恢复。

## 非目标

- 不把 Tollow 改成暗色。
- 不重做各产品业务功能或渲染算法。
- 不在本轮重新制作商城产品截图。
- 不加入商城页头页尾，也不恢复嵌入式圆角容器。
