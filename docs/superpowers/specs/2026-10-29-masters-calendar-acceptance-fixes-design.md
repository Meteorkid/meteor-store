# 硕士申请日历验收修复与全年总览优化

2026-10-29，用户已确认修复五个验收问题，并按上一轮建议优化体验。

## 数据与日期

- 同项目区间先排序再合并，保留真实间隙，每段标识唯一。
- 月历摘要只计本月节点，跨月补位格继续画连续色带。
- 月历今天与默认月份统一使用北京时间。
- 真实开放区间与最后截止里程碑分离，里程碑不延长时长或重叠天数。
- 每个截止标记携带自己的轮次 ID，点击和键盘定位均对应准确记录。
- 最近有效截止依据现有轮次状态计算；全部过期的行排在有效行之后。

## 交互

- 保留默认月历；“甘特”改称“全年总览”。视图与项目范围分组标注。
- 全年总览提供紧凑总览与放大时间轴，滚动只发生在图表内部。
- 明确标出跨年年份，重要文字不低于 white/60。
- 点击项目或时长条展开完整项目名和各轮日期，各轮均有列表定位入口。
- 最近截止与轮次数在行首可见，手机端不依赖悬停读取完整名称。

## 首次开放证据

使用现有详情 JSON 的可选字段，区分首次确认开放与最近核验日期，不增加数据库列。
只保存同一记录、同一项目/来源/入学季的已核验证据；不把创建时间当开放时间，
不推测未记录的历史日期。旧数据可使用自身上一次已核验开放证据，后续核验不移动起点。
服务层维护证据，管理员表单缺少该字段不能无意清除；单独新增该证据不触发截止改期提醒。
不执行生产批量回填或迁移。新代码读取旧 JSON 无需回填；旧版本 strict schema
不认识新增字段，回滚必须保留字段解析兼容补丁，不能直接退回旧应用。
未公布开放日且已明确关闭或开放状态未知的记录只显示截止点，不因截止日过去而重画历史长条。
