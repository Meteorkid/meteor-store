# Meteor Store

面向开发者的软件商店，提供精心打磨的工具与 AI 应用。

> 本仓库为私有仓库，仅供团队成员使用。

## 技术栈

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4
- Neon Postgres + Drizzle ORM
- Upstash Redis

## 本地开发

```bash
pnpm install
pnpm dev
```

## 部署

项目同时部署在 Vercel 和自托管服务器上。部署相关文档和脚本参见 `deploy/` 目录。
