## How It Started

I'm a college student. In my spare time I've built quite a few small projects — a crawler framework, a typing trainer, a macOS utility. They were scattered across GitHub, with no one really knowing they existed.

I wanted to give these projects a home. Not the cold, list-style GitHub Profile, but a real product showcase — with screenshots, with stories, with that "I want to try it" impulse.

## Tech Choices

- **Next.js 16** + **React 19**: App Router, Server Components, streaming rendering
- **Tailwind CSS 4**: site-wide dark theme, liquid-glass aesthetic
- Deployed on **Vercel**: push to ship

The whole site was built by me working alongside Claude Code. From design drafts to code, AI was my collaborator, not a replacement.

## Nine Products

Each one scratches an itch of my own:

| Product | What problem it solves |
|------|-------------|
| OmniCrawl | Data collection is painful |
| Ex-Memory | I want to chat with AI, but AI has no personality |
| Skeleton Anatomy | Anatomy learning tools are too old-school |
| Statux | You can't see AI Agent status in the terminal |
| XIsland | macOS doesn't have Dynamic Island |
| Tollow | Typing practice only has short sentences, no long-form text |

## Open Source

Everything is open source, everything is free. Students who email me can get every paid feature for free.
