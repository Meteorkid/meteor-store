## Pathfinder 是什么

Pathfinder 是面向大学生的公益信息与学习路径中心，网址是 `/pathfinder`。它聚合四类内容：

- 适合第一次参与贡献的开源项目
- 面向大学生的竞赛与挑战
- 实习岗位与官方招聘入口
- 来自官方信源的 AI 动态

它不只是资讯列表。经过核验且具备学习价值的条目会被标注难度、方向、投入时间和现实条件，用来生成一份 4–8 周的可执行学习路径。

## 浏览可信目录

进入 Pathfinder 后，可以从顶部子导航切换「发现」「机会」「方向」和「我的路径」。无需登录即可浏览。

「发现」页展示编辑精选、近期截止、最新机会与 AI 动态；「机会」页可以按内容类型、技术方向、难度、远程状态筛选；目录存在标准截止时间时还会显示截止筛选。搜索与筛选会写入网址，复制链接即可分享当前结果。

每张信息卡都会标注：

- 发布者或组织方
- 信息类型、方向和难度
- 原始来源与可信等级
- 最后核验时间
- 已知截止时间或「以原站为准」的说明

打开详情页后，可以查看适用对象、前置条件、预计投入、完成后可留下的成果，以及官方原文链接。Pathfinder 只保存事实字段和短摘要，不复制原站完整正文；报名、投递或贡献前请再次核对原文。

## 以真实机会为目标生成路径

在任意可用于学习的开源项目、竞赛或实习详情中点击「以此制定路径」，也可以直接进入「我的路径」。表单会询问：

- 想达成的目标和方向
- 当前年级与基础
- 每周可投入时间和计划周数
- 可用设备、网络和预算
- 碎片时间、基础薄弱、缺少导师等现实限制

Pathfinder 会先排除已过期、预算或设备不匹配的条目，再按目标、难度衔接、来源可信度、时效和投入产出排序。这个过程使用确定性规则，不需要配置 AI 模型或 API Key。

如果你选择“零基础”，而当前目录没有能可靠衔接该方向的入门资源，系统会明确说明暂时无法生成，不会跳过 Python 或编程基础直接给出高级贡献任务。带有学校名单、预计毕业日期等复杂资格的机会只供发现，必须先在官网人工核对，不会自动排入路径。已知外币费用也只有在你明确接受外币支出后才可能参与规划。

## 理解路径结果

路径持续 4–8 周，通常依次覆盖准备、练习、真实行动、交付和复盘。每周都包含：

- 清晰的阶段目标
- 一到数个具体任务
- 预计用时
- 对应的可信目录条目
- 可验证的完成证据，例如提交记录、作品链接、报名材料或模拟面试记录
- 原资源失效时的替代行动

竞赛或实习存在截止日期时，系统会倒排进度；剩余时间不足时会给出警告，不承诺无法保证的结果。AI 动态只用于了解方向变化，不会被当作已完成的学习任务。

## 保存进度与隐私

首版路径和任务勾选状态只保存在当前浏览器的本地存储中：

- 不需要注册或登录
- 不会将个人画像和进度写入 Meteor Store 数据库
- 清除浏览器数据会同时删除已保存路径
- 暂不支持跨设备同步

目录条目被标记失效或过期后，旧路径仍会保留，但页面会提示重新规划。

## 信息如何更新

Pathfinder 优先使用官方 API、RSS 和官方页面。自动采集内容默认进入待审核队列，核对来源、资格与时效后才会公开；稳定且明确授权的官方来源才可能自动发布。

系统会保留原始链接和最后核验时间。信息可能在原站临时变更，涉及报名、投递、费用、资格或截止日期时，请始终以发布方原文为准。

## 常见问题

### 需要自己的 API Key 吗？

不需要。路径核心使用站内可信目录和确定性规则生成。

### 必须登录吗？

不需要。浏览、筛选、生成路径和本地记录进度均可匿名使用。

### 为什么有些 AI 动态不能加入路径？

资讯热度不等于学习价值。只有经过审核、具备明确行动和成果标准的条目才能进入路径。

### 为什么找不到某个竞赛或岗位？

首版优先保证来源可信和信息可执行，不追求全网数量。未确认资格、截止时间或原始来源的内容不会直接公开。
