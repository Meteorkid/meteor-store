## 什么是 Pathfinder



![Pathfinder 目标输入表单](/help/use-pathfinder/zh/step-01-goal-form.webp "Pathfinder 页面")Pathfinder 是 Meteor Store 提供的免费行动方案生成工具，网址是 `/pathfinder`。你输入一个目标，描述你当前的情况和限制条件，Pathfinder 会为你生成一份结构化的执行计划——包含具体任务、完成标准、所需资源和每一步的操作建议。

这个工具的核心理念是：很多人不是没有目标，而是不知道从哪一步开始。Pathfinder 把模糊的想法拆解成可执行的步骤，帮你跨过「想到」和「做到」之间的那道坎。

## 打开 Pathfinder

![Pathfinder 目标输入表单](/help/use-pathfinder/zh/step-01-goal-form.webp "Pathfinder 页面，包含目标描述、现实条件和排除项三个输入框")

Pathfinder 对所有人开放，不需要登录。进入方式：

- 点击顶部导航栏的「Pathfinder」入口
- 直接在浏览器输入 `https://imagentx.top/pathfinder`

页面打开后，你会看到页面的标题和说明，下方是痛点说明区、方案生成区和公益承诺区。

## 使用预设案例快速体验

如果你只是想先看看 Pathfinder 能产出什么样的方案，最快的方式是点击预设案例卡片。页面中部的「预设方案」区域提供了三个典型场景，点击任意卡片会立刻展示该场景下的完整行动方案。

每个预设案例包含：

- 一个具体的场景描述（如「想入门前端开发但不知道从哪里开始」）
- 一份由真实 AI 模型生成并经过人工审核的行动方案
- 方案中的任务拆分、资源推荐和现实约束提示

预设案例不需要你填写任何信息，也不消耗任何 API 额度，点击即看。

## 生成你自己的行动方案

要生成针对你个人情况的方案，需要先配置 AI 模型，然后填写目标表单。

### 配置 AI 模型

Pathfinder 通过调用外部 AI 模型来生成方案。你需要先在「配置」页面设置模型连接信息：

1. 点击「配置模型」按钮，进入 `/pathfinder/settings` 页面
2. 填写模型提供商、API 地址、模型名称和 API Key
3. 保存后回到 Pathfinder 页面

配置信息**只保存在你的浏览器本地存储中**，不会上传到 Meteor Store 服务器。每次生成方案时，配置从你的浏览器直接发给 Pathfinder API，Meteor Store 的服务器不会看到或存储你的 API Key。关闭页面或清除浏览器数据后，配置会被清除。

### 填写目标表单

配置好模型后，在表单区域填写以下信息：

- **你的目标**：用一句话描述你想达成什么。越具体越好——「三个月内学会 React 并做出一个个人网站」比「学前端」更能产出实用的方案
- **现实条件**：描述你当前的起点和限制，比如「每天只有 1 小时可用」「没有编程基础」「预算 500 元以内」。这些信息会体现在方案的约束提示中
- **排除项（可选）**：如果你已经知道某些做法不适合你（比如「不考虑报培训班」「只用免费资源」），写在这里

填写完成后点击「生成方案」，等待几秒到十几秒，方案会出现在表单下方。

## 理解行动方案的结构

生成的方案包含以下组成部分：

### 方案摘要

一句话概括整个方案的主线——让你用最短的时间确认方向对不对。

### 任务列表

方案按执行顺序拆分成多个任务。每个任务包含：

- **任务标题**：这一阶段要完成的核心事项
- **完成标准**：怎样算做完了——可验证的判断条件，比如「能在本地运行一个 React 项目」「完成了 5 道 LeetCode 中等难度题」
- **关键步骤**：完成这个任务具体需要做的 2 到 4 件小事
- **现实约束提示**：结合你填写的现实条件，在相关任务旁边标注注意事项，比如「考虑到你每天只有 1 小时，这个任务预计需要 5 到 7 天」

### 免费资源与工具

方案末尾会推荐与你的目标相关的免费资源和工具，包括教程、开源项目、在线工具等。所有推荐资源来自 Meteor Store 维护的免费资源库。

### 重新生成

如果你对生成的方案不满意，可以点击「重新生成」按钮回到表单，修改目标描述或现实条件后再次生成。

## Pathfinder 的免费承诺

Pathfinder 页面底部的公益承诺区明确说明了四条原则：

- **完全免费**：Pathfinder 不收费。你用任何 AI 模型生成方案都不会经过 Meteor Store 的计费系统
- **不收集用户数据**：你的目标内容、现实条件和生成的方案都不会存到 Meteor Store 服务器。方案生成请求只经过 API 中转，不落库
- **不包含广告**：方案中不会植入产品推荐、付费推广或软广内容
- **不主动联网**：除了你指定的 AI 模型 API 之外，Pathfinder 不会向其他服务器发送数据

你需要自己提供 AI 模型的 API Key，Meteor Store 不承担模型调用产生的费用。

## 常见问题

### 必须配置自己的 API Key 吗？

是的。Pathfinder 本身不提供 AI 模型服务——它只是一个生成方案的工具框架。你需要提供自己已有的模型 API Key（如 DeepSeek、OpenAI 等兼容接口）。如果你暂时没有 API Key，可以先使用预设案例了解 Pathfinder 的能力。

### 生成的方案有多可靠？

方案由 AI 模型根据你提供的信息生成，质量和可行性取决于模型能力以及你输入的描述质量。建议把方案当作方向性参考，执行过程中根据实际情况调整步骤。

### 方案可以保存或分享吗？

当前版本不支持在 Pathfinder 页面内保存方案。你可以截图或复制方案内容到自己的笔记工具中。刷新页面或关闭浏览器后，方案结果不会保留。
