## 打开在线应用

从「产品」菜单选择「在线体验」，或直接访问[在线体验](/playground)。选择「打开应用」后，应用会在新窗口全屏打开。

- Skeleton Anatomy、Chakra Visualizer 和流体模拟可以直接使用。需要摄像头的交互会在你开启后请求权限。
- Tollow 需要登录商城账号，以便保存练习进度和收藏。登录后会返回 Tollow。
- Ex-Memory 需要登录，并在模型设置中配置自己的对话与文本向量 API Key。模型调用由你选择的服务商按账户计费。首次使用可查看[模型设置与导入指引](/docs/ex-memory-first-import)。

你也可以从站内搜索直接打开应用。例如，输入「打字」后选择「打开 Tollow」。

## 看产品演示

在页面下方的「产品演示」区选择 OmniCrawl、Ex-Memory、Statux 或 Tollow，再点击「看演示」。模拟终端会依次展示预先编排的命令与输出，可用右上角的重播按钮重新观看。

![产品演示的标签和模拟终端](/help/use-playground/zh/step-01-playground-tabs.webp)

观看这些示例无需登录或 API Key。想用自己的内容练习或导入资料时，回到页面上方选择对应应用。
