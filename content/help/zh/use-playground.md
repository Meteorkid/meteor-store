## 打开在线应用

访问[产品目录](/products)，打开想体验的产品详情，选择「打开应用」或「登录后打开应用」。应用会在新窗口全屏打开。

- [Skeleton Anatomy](/products/skeleton-anatomy)、[Chakra Visualizer](/products/chakra-visualizer)和[流体模拟](/products/webgl-fluid-sim)可以直接使用。需要摄像头的交互会在你开启后请求权限。
- [Tollow](/products/tollow)需要登录商城账号，以便保存练习进度和收藏。登录后会返回 Tollow。
- [Ex-Memory](/products/ex-memory)需要登录，并在模型设置中配置自己的对话与文本向量 API Key。模型调用由你选择的服务商按账户计费。首次使用可查看[模型设置与导入指引](/docs/ex-memory-first-import)。
