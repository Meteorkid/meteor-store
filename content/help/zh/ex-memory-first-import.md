## 从示例开始

Ex-Memory 根据聊天记录建立个人记忆镜像，参考记录中的表达方式进行 AI 模拟对话，并允许纠正人物信息和记忆。生成回复可能出错，不代表本人说过的话或真实想法。

在 [产品页](/products/ex-memory) 点击「在线体验」，登录 Meteor Store 后即可进入。当前在线试用无需购买或免费入库；方案购买尚未开放。试用可用额度以应用内显示为准。

第一次使用，建议在应用内下载**虚构聊天示例**，用它走通导入流程。示例不是其他用户的聊天记录。

## 导入并创建镜像

1. 选择聊天文件。可以先使用虚构示例；导入真实记录时，请只使用本人或已获授权的资料，删去与体验无关的敏感内容。可用格式与大小限制以导入界面的提示为准。
2. 填写镜像名称，以及**聊天记录中实际出现的目标说话人名称**。镜像名称用于区分人物；目标说话人用于确定参考谁的表达，不能随意填一个记录里没有的称呼。
3. 阅读并确认在线存储与模型处理说明，再选择「导入并创建」。未确认时，系统不会开始上传。
4. 等待导入和人物资料生成完成，再开始对话。导入失败与创建成功是两个不同状态，请按照页面提示处理。

如需从微信获取聊天文件，可查看应用内的导出指引。本机助手的导出步骤在你的电脑上执行；文件上传后会进入在线服务。

## 第一次对话怎么试

先问一个能从记录中核对的问题，例如「记录里提到过哪些周末安排？」。把回复与原始记录对照，观察事实是否准确、表达是否合适。

发现错误时，使用镜像内的纠正入口补充正确的人物信息或记忆，再继续提问。AI 回复和用户纠正均不同于原始聊天记录，不应作为本人表态的证据。

## 导入失败后继续

- **没有解析到消息或找不到目标说话人**：核对文件格式、内容与说话人名称，修改后重新导入。
- **人物资料生成失败**：按页面提示检查模型配置或稍后重试。若页面保留了待完成镜像，继续为它导入，不必反复创建新镜像。
- **体验服务长时间未响应**：选择「重新加载」；仍无法进入时，返回产品页并 [反馈问题](/feedback?type=question)。描述步骤和错误提示即可，请勿提交完整私人聊天或 API Key。

## 数据在哪里处理

在线试用会把上传的聊天记录、人物资料和记忆、模拟对话及纠正内容保存在网站服务器，并关联到你的 Meteor Store 用户 ID。为了建立检索索引、生成画像和回复，必要的内容会发送至所配置的文本向量（embedding）和对话模型服务。

本机导出与在线处理是两个阶段。使用本机助手导出，不表示后续上传、检索与对话都在本机完成。服务商与处理位置取决于当前模型配置；请在上传前阅读应用中的数据处理说明和 [隐私政策](/privacy#ex-memory)。

镜像可在应用内删除。其他留存资料或撤回授权请求可通过隐私政策中的联系方式处理；删除镜像不会自动撤回已经发送给模型服务商的请求。
