## 欢迎来到 Meteor Store



![Meteor Store 首页](/help/start-here/zh/step-01-homepage.webp "Meteor Store 首页")Meteor Store 是一个面向开发者和创意工作者的工具站，由一位独立开发者搭建和维护。店里既有可以直接在浏览器中打开的在线应用，也有需要下载到本地的 macOS 工具，还有一些以授权码形式发放的软件产品。

如果你是第一次打开这个网站，这篇文章会带你快速了解这里有什么、从哪里开始。

## 首页有什么

首页是你认识这座小店的第一窗口。从上到下的区块分别是：

- **品牌标识与导航栏**：点击左侧的 "Meteor Store" 标识可回到首页。导航按「产品」「每日一新」「学习与机会」「内容」「帮助」分成五组，展开后选择具体入口。点击搜索按钮，或在未输入文字时按 `/`、`⌘K`（Windows 上 `Ctrl+K`），可以打开全站搜索。
- **Hero 主视觉**：上来第一屏展示了店主对他所做的事的一句话概括。
- **合作伙伴与产品展示**：往下滚动可以看到已经上架的产品卡片，每张卡片包含名称、简介和最低价格。
- **定价区**：销售功能开启时，会展示 Meteor Pass 产品线通行证的月付、年付和买断档位。Pass 覆盖主产品线，具体范围以定价页的说明为准。
- **常见问题**：定价区下面收了一组新用户最常问的问题，比如退款政策、如何获取产品以及 macOS 的安全提示。
- **页脚**：页面最下面是页脚，包含主线产品的链接、资源入口（帮助、博客、关于店主）、联系与反馈入口，以及隐私政策、服务条款等说明。

## 从哪里开始

根据你想做的事，可以从这几条路径里选一条：

- **想看看店里有什么**：展开「产品」，选择「查看全部产品」；主线工具和实验室项目都在产品页。每个产品都有自己的详情页，写明功能和获取方式。
- **想免费上手试试**：有些产品提供 ¥0 免费档，登录后在产品详情页点「免费入库」即可添加到账户。骨骼、手势和流体展示支持公开体验；Tollow 需要登录来同步进度。具体要求以入口提示为准。
- **想了解 Meteor Pass**：在「产品」菜单里打开「Meteor Pass 与定价」。它覆盖主产品线；实验室项目本来就免费，无需为了它们购买 Pass。未来产品是否纳入，以产品线与权益说明为准。
- **想每天读一点**：打开「每日一新」，选择英语、论文、AI、活动、开源、竞赛或实习栏目。硕士申请全年日历位于「学习与机会」中。
- **想读文章或投稿**：展开「内容」，进入全部文章或某个分区，也可以订阅 RSS。登录后的用户菜单提供投稿入口，文章通过审核后公开发布。
- **遇到问题或想联系店主**：展开「帮助」，选择帮助中心、联系或问题反馈。

## 几个需要先知道的概念

### 产品 vs Meteor Pass

店里有两类「可以买到」的东西：**单品**和 **Meteor Pass**。单品是你为某一个产品单独付费，授权没有到期时间。Meteor Pass 是主产品线通行证，可按月、按年或买断；月付和年付有有效期，买断永久有效。单独购买的产品授权不会因 Pass 到期而失效。

### 站内应用 vs 下载应用 vs 授权码

产品拿到手的方式有三种：有些是浏览器里直接打开的 Web 应用，有些是需要下载到 Mac 上的 dmg 安装包，还有一些是给你一个授权码、你在别的地方激活使用。在决定购买之前，可以先看产品详情页上的说明，确认它属于哪一类。

### 登录与账户

浏览、看博客、打开帮助中心都不需要登录。只有涉及购买、投稿、收藏、评论这些操作时，才需要注册一个账户。注册需要验证邮箱；邮箱没验证之前不能登录。

### 开源项目

「产品」菜单里的「开源作品」列出了店主以 MIT 许可证发布的项目。可以免费获取这些项目的源码，无需通过商店支付。
