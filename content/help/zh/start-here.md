## 欢迎来到 Meteor Store



![Meteor Store 首页](/help/start-here/zh/step-01-homepage.webp "Meteor Store 首页")Meteor Store 是一个面向开发者和创意工作者的工具站，由一位独立开发者搭建和维护。店里既有可以直接在浏览器中打开的在线应用，也有需要下载到本地的 macOS 工具，还有一些以授权码形式发放的软件产品。

如果你是第一次打开这个网站，这篇文章会带你快速了解这里有什么、从哪里开始。

## 首页有什么

首页是你认识这座小店的第一窗口。从上到下的区块分别是：

- **品牌标识与导航栏**：页面顶部有一条始终可见的导航栏，左侧是 "Meteor Store" 字样和流星图标，右侧列出了产品、帮助、博客、开源项目和 Pathfinder 等主要入口。导航栏底下还有一个搜索按钮，按下 `⌘K`（Windows 上 `Ctrl+K`）可以打开全站搜索。
- **Hero 主视觉**：上来第一屏展示了店主对他所做的事的一句话概括。
- **合作伙伴与产品展示**：往下滚动可以看到已经上架的产品卡片，每张卡片包含名称、简介和最低价格。
- **定价区**：再往下是 Meteor Pass（全站会员）的定价区块——月付、年付、买断三个档位，买一张 Pass 就同时拥有店里所有产品的使用授权。
- **常见问题**：定价区下面收了一组新用户最常问的问题，比如退款政策、如何获取产品以及 macOS 的安全提示。
- **页脚**：页面最下面是页脚，包含全部产品的链接、资源入口（帮助、博客、关于店主）、公司信息（联系、反馈入口）和法律条款（隐私政策、服务条款、退款政策）。

## 从哪里开始

根据你想做的事，可以从这几条路径里选一条：

- **想看看店里有什么**：点顶部导航的「产品」或往下滚到产品展示区，浏览所有上架产品。每个产品都有自己的详情页，写明了功能列表、价格和下载方式。
- **想免费上手试试**：有些产品提供 ¥0 免费档——在产品详情页点「免费入库」就会加到你的账户。支持在线试用的产品还有「免费试用」入口，不登录也能在浏览器里直接体验。
- **想买全站会员**：如果看上了好几款产品，Meteor Pass 通常比单买划算。Pass 覆盖了站内全部产品，包括将来新上架的。
- **想读文章或投稿**：顶部「博客」入口进去是店主和读者的文章，按主题分成多个分区，支持 RSS 订阅。注册登录后你也可以投稿，通过审核后会公开发布。
- **遇到问题或想联系店主**：顶部的「帮助」入口是帮助中心，按分类整理了常见问题的答案。页脚的「反馈」入口可以直接提交问题给店主。

## 几个需要先知道的概念

### 产品 vs Meteor Pass

店里有两类「可以买到」的东西：**单品**和 **Meteor Pass**。单品是你为某一个产品单独付费，买完就一直能用。Meteor Pass 是全站会员，买了之后所有产品都归你用，按月付、年付或买断付费。Pass 会过期（买断除外），单品不会。

### 站内应用 vs 下载应用 vs 授权码

产品拿到手的方式有三种：有些是浏览器里直接打开的 Web 应用，有些是需要下载到 Mac 上的 dmg 安装包，还有一些是给你一个授权码、你在别的地方激活使用。在决定购买之前，可以先看产品详情页上的说明，确认它属于哪一类。

### 登录与账户

浏览、看博客、打开帮助中心都不需要登录。只有涉及购买、兑换、投稿、收藏、评论这些操作时，才需要注册一个账户。注册需要验证邮箱；邮箱没验证之前不能登录。

### 开源项目

导航栏上的「开源项目」入口列出了店主以 MIT 许可证发布的开源作品。它们的使用方式和普通产品不同——可以免费获取源码，不需要登录，也不需要通过商店的支付系统。
