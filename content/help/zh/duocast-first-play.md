## 准备 Mac 和输出设备

DuoCast 将同一路音频分发到最多 3 路输出，每路可分别调节音量、延迟和 10 段 EQ。当前安装包适用于 **macOS 14.2 及以上、Apple Silicon 芯片**的 Mac，Windows 暂无安装包。

先接好要使用的耳机或扬声器，再打开应用。可以从一副有线耳机搭配一副蓝牙耳机开始；两副蓝牙耳机能否同时播放受系统与设备限制，DuoCast 不保证这种组合可用。

## 下载、核对并安装

1. 打开 [DuoCast 产品页的下载区](/zh/products/duocast#download)，下载 macOS 安装包，无需登录。下载卡会显示当前版本和文件名。
2. 核对下载来源与 SHA-256。文件名以产品页下载卡为准；若文件保存在默认「下载」文件夹，把文件名代入下面的命令，在「终端」运行：

   ```bash
   shasum -a 256 ~/Downloads/DuoCast-<版本>-macOS-arm64.zip
   ```

   完整校验值见产品页当前版本对应的 [GitHub Release](https://github.com/Meteorkid/duocast/releases) 发布说明。校验不一致时，先重新下载或反馈问题。
3. 解压 ZIP，将 `DuoCast.app` 拖入「应用程序」。
4. 打开应用。当前构建采用 **ad-hoc 签名，未经 Apple 公证**。如果 macOS 提示无法验证开发者或无法检查恶意软件，在确认来源可信且校验值一致后，进入「系统设置 → 隐私与安全性」，找到 DuoCast，点「仍要打开」，再按提示确认。

该步骤只为这一款应用设置例外，Apple 的操作说明见[《在 Mac 上安全地打开 App》](https://support.apple.com/zh-cn/102445)。如果系统提示“已损坏，无法打开”，先确认文件来自本站且校验值一致；仍无法打开时，可在“终端”运行下面的命令，只移除 DuoCast 这一份应用的隔离属性，再重新打开：

```bash
xattr -dr com.apple.quarantine "/Applications/DuoCast.app"
```

不要关闭 Gatekeeper，也不要对系统或其他应用执行绕过安全检查的命令。如果问题仍存在，请[反馈问题](/zh/feedback?type=question)，附上完整提示文字。

## 完成第一次播放

1. 在每张输出卡片顶部的下拉菜单中选择耳机或扬声器。先用两路确认声音，再按需要增加至三路。
2. 在左上角选择「系统声音」或「音频文件」。使用系统声音时，可通过「采集：全部 App」选择要采集的应用；使用音频文件时，选择本地文件。
3. 先将各路音量调低，点「开始分发」。系统声音模式下，再在选中的应用中播放音频；音频文件模式使用已选文件。
4. 首次采集系统声音时，按系统提示授予「录屏与系统录音」权限。也可在「系统设置 → 隐私与安全性 → 录屏与系统录音」中找到 DuoCast 并允许访问，再按系统提示继续。

没有这项权限时，系统音频可能只有静音。确认权限和输入源后，再检查各路输出设备及音量。

## 调节音量、延迟和 EQ

- **音量**：在对应输出卡片中逐步调整，每路互不影响。
- **延迟**：先听出哪一路更快，把延迟加在更快的一路上。混用有线和蓝牙时，通常需要延后有线耳机或内置扬声器，让它跟上蓝牙。
- **EQ**：按每副耳机的听感调整 10 段均衡。音量、延迟和 EQ 会按设备保存，下次使用同一设备时恢复。

设备支持热插拔；断开一个设备只停止对应输出。增删输出通道会停止分发，调整好通道后再开始播放。

## 停止播放与排查

在控制面板中点「停止分发」即可停止音频分发。**关闭窗口不会退出应用**；也可右键点按 Dock 中的 DuoCast 图标，选择停止或重新显示控制面板。锁屏或休眠会停止分发，唤醒后需要手动开始。

如果某一路没有声音，依次检查该设备是否仍连接、卡片是否选中了正确设备、音量是否过低。系统声音全部静音时，检查采集权限和所选 App。两副蓝牙耳机只有一副出声时，先换成有线与蓝牙组合核对，避免把蓝牙链路限制当成音量问题。

仍未解决时，请[反馈问题](/zh/feedback?type=question)，写明 DuoCast 版本、macOS 版本、设备组合、输入源和出现问题的步骤。项目说明与更新记录见 [DuoCast GitHub 仓库](https://github.com/Meteorkid/duocast)。
