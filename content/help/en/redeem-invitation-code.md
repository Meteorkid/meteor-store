## For previously issued invitation codes only

This page is kept for people who already received an `INV-XXXX-XXXX-XXXX` invitation code and need the original redemption process or historical entitlement information. New software activation codes have 1 month, 1 year, or Lifetime terms. Purchased codes and administrator grants are shown in your account and activated inside the app; see the [software activation code guide](/en/docs/use-license-key).

## Use the original redemption link

Previously issued INV codes can still be handled on the [original redemption page](/en/redeem). Sign in, verify the email of the original receiving account, and enter the complete code you received. The homepage and account shortcuts no longer offer a new invitation-code entry.

Historical invitation codes belong to the original website redemption flow. Do not enter them in the new XNook or XIsland activation field. Existing entitlements continue to follow their original issuance records.

## Redemption steps

1. Log in and open the redemption page.
2. Paste or type the full invitation code into the input field. Codes are case-insensitive; the system converts them to uppercase automatically.
3. Click the "Redeem" button.
4. The system validates the code behind the scenes — checking whether it exists, whether it still has remaining uses, whether it has expired, and whether you have already redeemed this exact code.
5. If validation passes, the system generates a new license key and records the redemption. The license key appears in your Account page.

After a successful redemption, you can find the product on your My Products page and use it normally. No purchase flow is needed.

## Why redemption might fail

Redemption can fail for several reasons. The system provides a clear error message in each case:

- **Code does not exist** — Double-check that you typed the full code including the hyphens. Copy-pasting is recommended over manual entry.
- **Code is used up** — Each invitation code has a maximum number of redemptions. Once all uses are claimed, the code expires.
- **Code has expired** — Some codes include an expiry date. Expired codes cannot be redeemed.
- **You have already used this code** — Each user can redeem a given invitation code only once.

## Can I combine invitation codes with purchases

Yes. Licenses obtained through invitation codes and those obtained through purchases or free claims are independent of each other. If you redeem a code for a product and later buy a different tier of the same product yourself, both license records appear in your account separately.

Meteor Pass also covers products you obtained through invitation codes. On the My Products page, these products carry the appropriate badge to help you distinguish the source of each entitlement.

## Where to find your license key after redemption

After logging in, click your avatar in the top-right corner and select "Account." The account page lists all your license keys. Each entry shows the associated product, order ID, and generation time.

If you redeemed an invitation code for Meteor Pass, the Pass coverage appears on the My Products page as site-wide access rather than a standalone license key entry — this depends on the product type the code was created for. If anything is unclear, reach out to the store owner through the "Feedback" link in the footer.
