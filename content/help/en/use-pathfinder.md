## What is Pathfinder

Pathfinder is a free action-plan generator provided by Meteor Store, available at `/pathfinder`. You describe a goal and your current situation, and Pathfinder produces a structured execution plan — with concrete tasks, completion criteria, recommended resources, and step-by-step guidance.

The core idea behind Pathfinder is simple: most people know what they want, but they do not know where to start. Pathfinder breaks a vague ambition into actionable steps, bridging the gap between thinking about something and actually doing it.

## Opening Pathfinder

Pathfinder is open to everyone; no login is required. You can reach it by:

- Clicking the "Pathfinder" link in the top navigation bar
- Typing `https://imagentx.top/pathfinder` directly into your browser

The page loads with a title and description, followed by a pain-points section, the plan-generation area, and a public-welfare commitments section.

## Trying preset cases first

If you just want to see what kind of output Pathfinder produces, the fastest way is to click one of the preset-case cards. The "Preset Plans" section in the middle of the page offers three typical scenarios. Clicking any card immediately shows the complete action plan for that scenario.

Each preset case provides:

- A concrete scenario description (e.g., "I want to get into front-end development but have no idea where to begin")
- A full action plan, originally generated by a real AI model and then reviewed by a human
- Task breakdowns, resource recommendations, and reality-constraint tips

Preset cases require zero input and consume no API quota — one click and the plan appears.

## Generating your own action plan

To get a plan tailored to your personal situation, you need to configure an AI model first, then fill out the goal form.

### Configuring an AI model

Pathfinder calls an external AI model to generate plans. You need to set up the model connection on the Settings page:

1. Click the "Configure Model" button, which opens `/pathfinder/settings`
2. Fill in the model provider, API endpoint, model name, and API key
3. Save, then return to the Pathfinder page

Your configuration is stored **only in your browser's local storage**. It is never uploaded to Meteor Store's servers. When you generate a plan, the configuration travels directly from your browser to the Pathfinder API — Meteor Store's servers never see or store your API key. Closing the page or clearing your browser data wipes the configuration.

### Filling out the goal form

Once the model is configured, fill in the form fields:

- **Your goal** — Describe what you want to achieve in one sentence. The more specific, the better. "Build a personal website with React within three months" produces a more practical plan than "learn front-end."
- **Reality constraints** — Describe your starting point and limitations, such as "only one hour per day available," "no programming background," or "budget under ¥500." These details will appear as constraint notes on relevant tasks.
- **Exclusions (optional)** — If you already know certain approaches will not work for you (e.g., "no paid courses," "free resources only"), list them here.

When ready, click "Generate Plan." After a few seconds, the plan will appear below the form.

## Understanding the plan structure

A generated plan consists of the following parts:

### Summary

A one-line summary of the entire plan — enough to confirm the direction is right in a single glance.

### Task list

The plan is broken into multiple tasks in execution order. Each task includes:

- **Task title** — The core thing to complete in this phase
- **Completion criteria** — Verifiable conditions for when the task is done, e.g., "A React project runs locally" or "Five LeetCode medium-level problems completed"
- **Key steps** — Two to four concrete actions needed to complete the task
- **Reality-constraint notes** — Based on the constraints you entered, relevant tasks carry annotations like "Given your one-hour-per-day limit, this task will likely take five to seven days"

### Free resources and tools

At the end of the plan, you will find free resources and tools relevant to your goal — tutorials, open-source projects, online tools, and more. All recommended resources come from a free resource library maintained by Meteor Store.

### Regenerating

If you are not satisfied with the generated plan, click "Regenerate" to return to the form. Edit your goal description or constraints, then generate again.

## Pathfinder's free commitment

The public-welfare section at the bottom of the Pathfinder page states four principles:

- **Completely free** — Pathfinder charges nothing. No plan generation goes through Meteor Store's billing system.
- **No user data collected** — Your goals, constraints, and generated plans are not stored on Meteor Store's servers. Plan-generation requests pass through the API as a relay without being persisted.
- **No advertisements** — Plans never include product recommendations, paid promotions, or sponsored content.
- **No telemetry** — Aside from the AI model API you specify, Pathfinder sends no data to any other server.

You need to supply your own AI model API key. Meteor Store does not cover the costs of model API calls.

## Frequently asked questions

### Do I have to provide my own API key?

Yes. Pathfinder itself does not offer an AI model service — it is a framework that generates plans by calling an external model. You need to bring your own API key from a compatible provider (such as DeepSeek, OpenAI, or compatible endpoints). If you do not have an API key yet, try the preset cases to see what Pathfinder can do.

### How reliable are the generated plans?

Plans are generated by an AI model based on the information you provide. Quality and feasibility depend on the model's capability and how clearly you describe your situation. Treat plans as directional guidance and adjust steps as you go.

### Can I save or share a plan?

The current version does not support saving plans within Pathfinder. You can take a screenshot or copy the plan content to your own note-taking tool. Refreshing the page or closing the browser will clear the plan result.
